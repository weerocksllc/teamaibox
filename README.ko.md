## Team AI Box의 특징

- **한 대의 통합 작업 공간.** AI, 협업, 가상 기기를 일관된 UI와 계정으로 이용합니다.
- **로컬 AI 우선.** Spark에서 모델 추론을 실행하고 필요에 따라 외부 모델 API를 연결하세요.
- **DGX Spark 전용 설계.** Ubuntu ARM64에서 NVIDIA GPU 컨테이너와 KVM 가상화를 활용해 설치하세요.
- **함께 개선하는 MIT 코드.** UI는 17개 언어와 밝은/어두운 테마를 지원하고 수동 선택을 기억합니다. 기본 언어는 영어입니다.

<a id="feature-workspace"></a>

### 작업 공간과 일상적인 탐색

- DGX Spark 한 대에서 로컬 AI, 팀 협업, 가상 기기를 하나의 브라우저 작업 공간으로 이용합니다.
- 앱을 범주별로 살펴보고 앱 목록을 검색하며 사이드바에서 앱을 엽니다.
- 각 앱의 로딩 진행 상황, 사용 가능 여부와 서비스 상태를 확인하세요.
- 작업 센터에서 대기 중, 실행 중, 완료, 실패, 취소된 작업을 추적하고 이용 가능한 결과를 엽니다.
- 알림 메뉴에서 응답을 기다리는 화면 공유 초대를 확인하고 화면 공유 앱을 열어 응답합니다.
- 오른쪽에서 왼쪽으로 표시되는 아랍어를 포함한 17개 인터페이스 언어 중에서 선택합니다. 다른 언어를 직접 선택하기 전까지 기본 언어는 영어입니다.
- 밝게, 어둡게, 시스템 설정에 맞춘 테마를 사용합니다. 직접 선택한 언어와 테마는 새로고침, 재로그인, 앱 화면 이동 후에도 유지됩니다.

<a id="feature-assistant"></a>

### AI 도우미와 권한을 관리하는 Agent 작업

- 대화를 시작하고 기록을 저장하며 이전 대화를 다시 엽니다.
- 현재 요청에 자동, 답변 또는 Agent 모드를 선택합니다.
- 요청에 여러 파일을 첨부하고 보내기 전에 첨부 파일을 제거합니다.
- 생성되는 답변을 실시간으로 읽고 실행 중인 작업을 중지하며, 다시 연결한 뒤 이벤트 수신을 이어갑니다.
- 반환된 모델 정보, 도구 활동, 출처, 사용량을 확인하고 작업에서 파일이 생성되면 내려받습니다.
- 확인이 필요한 Agent 작업의 범위를 살펴본 뒤 해당 작업을 승인하거나 거부합니다.
- 사용자별 샌드박스의 영구 작업 공간에서 Agent 작업을 실행합니다. 도구와 네트워크 접근은 관리자 정책을 따릅니다.

<a id="feature-drawing"></a>

### AI 이미지 생성

- 사용 가능한 이미지 모델로 텍스트 프롬프트에서 이미지를 생성합니다. 현재 앱은 이미지 편집이나 인페인팅 편집기가 아닙니다.
- 사용 가능한 모델 설정이 지원할 경우 자동 또는 빠른 생성 방식을 선택합니다.
- 정사각형, 가로, 세로 비율과 지원되는 출력 크기, 무작위 또는 고정 시드를 선택합니다.
- PNG, WebP 또는 JPEG 출력을 요청하고 결과를 미리 본 뒤 이미지를 내려받습니다.
- 대기열과 생성 진행 상황을 확인하고 작업을 취소하며 페이지를 다시 열어 현재 작업을 복구합니다.
- 결과에 기록된 실제 사용 모델과 생성 매개변수를 확인합니다.

<a id="feature-ocr"></a>

### 문자 인식과 교정

- PNG, JPEG, WebP, PDF를 업로드하거나 팀 드라이브에 있는 파일을 선택합니다.
- 언어 힌트를 지정하고 선택한 모델의 지원 범위 안에서 텍스트, Markdown 표, LaTeX 수식을 인식합니다.
- 페이지와 텍스트 블록별로 인식 결과를 검토하고 인식된 글자를 직접 수정합니다.
- 검토한 내용을 텍스트, Markdown 또는 JSON으로 내보냅니다.
- 원본을 다시 업로드하거나 인식하지 않고 저장된 인식 결과를 번역으로 전달합니다.
- 인식 작업을 추적하고 취소합니다. 현재 모델은 경계 상자 좌표나 신뢰도 점수를 제공하지 않습니다.

<a id="feature-transcription"></a>

### 녹음 및 실시간 음성 전사

- 로컬 또는 팀 드라이브에서 WAV, FLAC, OGG, WebM, MP3, M4A, AIFF, MP4 형식의 오디오·비디오를 선택합니다.
- 원본 미디어를 미리 보고 자동 언어 감지 또는 지원되는 언어 힌트를 사용합니다.
- 타임스탬프가 있는 전사 구간을 검토하고 텍스트를 편집합니다.
- 텍스트, JSON, SRT 또는 WebVTT 자막으로 내보냅니다.
- 저장된 전사 결과를 번역에 전달하고 현재 전사 작업을 추적하거나 취소합니다.
- HTTPS, 브라우저 권한, MediaRecorder, 실시간 서비스를 사용할 수 있을 때 마이크 입력을 실시간으로 전사합니다.
- 단어별 타임스탬프와 화자 분리는 지원되는 프로필에서만 사용합니다. 실험적인 화자 분리 처리에는 WAV 입력이 필요합니다.

<a id="feature-translation"></a>

### 텍스트·파일·미디어 번역

- 모델을 기반으로 한 60개 언어 목록에서 선택하고, 원문 언어를 자동으로 감지하거나 원문·대상 언어를 직접 선택하고 서로 바꿉니다. 모든 언어 쌍에서 동일한 품질을 보장하는 것은 아닙니다.
- 입력하거나 붙여 넣은 글을 번역하고 원문과 번역문을 구간별로 비교합니다.
- 이미지나 PDF를 업로드하거나 팀 드라이브에서 선택합니다. OCR이 준비되어 있으면 텍스트를 인식한 뒤 번역합니다.
- 전사 서비스가 준비되어 있으면 지원되는 오디오·비디오를 전사한 뒤 번역하며 구간 시간을 유지합니다.
- 저장된 OCR·전사 결과를 재사용하고 이용 가능한 중간 결과를 내려받습니다.
- 번역문을 편집하고 텍스트, Markdown 또는 JSON으로 내보냅니다. 오디오·비디오 결과는 SRT와 WebVTT도 지원합니다.
- 추출, 전사, 번역 단계를 확인하고 작업을 취소하며 페이지를 다시 열어 현재 작업을 복구합니다.
- 번역 언어 범위는 UI와 OCR·음성 인식의 지원 언어 범위와 별개입니다. PDF 번역은 텍스트 기반이며 원본 레이아웃 재현이나 일반적인 DOCX·XLSX 편집 기능이 아닙니다.

<a id="feature-messaging"></a>

### 팀 메시지

- 팀원을 찾아 일대일 대화를 시작하고 선택한 멤버들과 이름이 있는 그룹 채팅을 만듭니다.
- 전체, 읽지 않음, 그룹으로 채팅을 필터링하고 접근 권한이 있는 대화와 메시지를 검색합니다.
- 텍스트와 첨부 파일을 보내고 첨부 시점의 원본 파일 버전을 내려받습니다.
- 메시지를 실시간으로 받고 재연결 후 채팅 기록을 이어 보며 읽음·읽지 않음 위치와 멤버의 접속 상태를 확인합니다.
- Enter로 보내고 Shift+Enter로 줄을 바꾸며, 좁은 화면에서는 대화 목록과 채팅 화면을 전환합니다.
- 내 화면에서 메시지를 삭제하거나 내 채팅 기록을 비웁니다. 다른 참여자의 기록은 삭제되지 않습니다.
- 그룹에서 나가지 않고 내 대화 목록에서 채팅을 삭제합니다. 새 메시지가 오면 다시 나타날 수 있습니다.

<a id="feature-drive"></a>

### 팀 드라이브와 파일 협업

- 폴더와 경로 탐색을 이용해 개인 및 팀 파일 공간을 정리합니다.
- 목록·격자 보기를 전환하고 파일 세부 정보를 확인하며 파일·폴더를 검색하고 최근 변경 사항을 살펴봅니다.
- 여러 파일을 업로드하고 진행 상황을 확인하며 업로드를 취소합니다.
- 같은 파일을 다시 선택해 대용량 파일의 분할 업로드를 재개합니다. 이미 업로드된 부분은 서버에서 검증합니다.
- 폴더를 만들고 파일과 폴더의 이름을 바꾸거나 이동·복사합니다.
- 지원되는 이미지, 오디오, 비디오, 텍스트, PDF를 미리 보고 파일을 내려받습니다. 미디어 재생 지원은 브라우저에 따라 달라집니다.
- 새 파일 버전을 업로드하고 버전 기록을 확인하며 이전 버전을 내려받습니다.
- 항목을 휴지통으로 이동하고 복원합니다.
- 보기·편집 권한과 선택적인 만료 시간을 지정해 멤버 또는 팀과 내부적으로 공유합니다. 익명 공개 링크 공유는 아닙니다.
- 나에게 공유된 파일과 폴더를 탐색합니다. 현재 권한과 멤버 자격을 기준으로 접근 권한을 다시 확인합니다.

<a id="feature-casting"></a>

### AirPlay 호환 무선 화면 공유

- 같은 LAN의 호환 Apple 기기를 위한 임시 수신기를 시작하고 중지합니다. 수신기는 고유한 이름과 PIN을 사용합니다.
- 수신기 유효 시간을 15분, 30분, 60분, 120분 중에서 선택합니다. 중지하거나 만료되면 수신기 알림과 시청 접근이 종료됩니다.
- 시청 범위를 나만, 선택한 멤버, 팀으로 제한하고 시청자를 초대합니다. 초대받은 사람은 수락하거나 거절할 수 있습니다.
- 브라우저에서 화면과 소리를 재생합니다. 브라우저 자동 재생 규칙에 따라 소리를 켜려면 클릭이 필요할 수 있습니다.
- 연결된 시청자를 확인하고 내보냅니다. 관리자는 비공개 내용을 볼 권한을 얻지 않고도 세션을 중지할 수 있습니다.
- 연결 끊김·재연결 상태를 확인하고 다시 참여할 때 시청 권한을 재확인합니다.
- 준비된 미디어 실행 환경, 접근 가능한 LAN 검색, 호환되는 브라우저·기기 버전이 필요합니다. 브라우저 시청 기능은 HDMI 출력, DRM·FairPlay 재생 또는 Apple 인증을 제공하지 않습니다.

<a id="feature-phones"></a>

### 데이터가 유지되는 가상 Android 휴대전화

- 설치된 시스템 프로필에서 독립적인 Android 휴대전화를 만듭니다. 각 휴대전화의 앱과 데이터는 세션이 바뀌어도 유지됩니다.
- 개별 휴대전화를 시작, 종료, 재시작, 이름 변경하거나 명시적으로 삭제합니다.
- 키보드·포인터 입력과 뒤로, 홈, 최근 앱, 볼륨 버튼으로 Android를 제어합니다.
- 오디오와 전체 화면을 사용하고 다시 연결하거나 현재 휴대전화 연결을 다른 페이지로 옮깁니다.
- 휴대전화에 파일을 업로드하고 휴대전화의 Team AI Box 전송 폴더에서 파일을 내려받습니다.
- 확인 후 본인의 APK 파일을 설치합니다. Android 앱 권한은 사용자 모르게 부여되지 않습니다.
- 지원되는 경우 이미지, 비디오 또는 브라우저 카메라를 가상 카메라 입력으로 사용합니다. 물리 USB 카메라와 네트워크 입력에는 관리자 설정과 권한도 필요합니다.
- 표준 ADB 도구와 Node.js 릴레이 클라이언트를 사용해 유효 기간이 짧은 릴레이를 통한 기기 한정 ADB 디버깅을 일시적으로 허용합니다.
- 필요할 때 프레임률, 패킷 손실, 연결 왕복 시간 통계를 확인합니다. 이 값들은 종단 간 지연을 보장하지 않습니다.
- 필요한 리소스가 있을 때만 Google Play 시스템 프로필을 선택합니다. 사용 가능하다는 사실이 Play Protect 인증이나 모든 Android 앱의 작동 보장을 뜻하지는 않습니다.

<a id="feature-computers"></a>

### 가상 Windows 및 Linux 컴퓨터

- CPU, 메모리, 디스크 크기를 선택해 독립적인 ARM64 Windows·Linux 컴퓨터를 만듭니다.
- 컴퓨터를 시작하고 정상 종료하며, 명시적 확인 후 중지된 컴퓨터를 삭제합니다.
- 원격 데스크톱에 먼저 로그인하지 않아도 브라우저 가상 모니터에서 펌웨어, 부팅, 설치, 운영체제 화면을 봅니다.
- 키보드, 포인터, 소리, 전체 화면, 재연결 제어를 사용합니다.
- 동일한 가상 컴퓨터를 여러 브라우저 탭이나 창에서 여세요.
- 팀원을 모니터 보기 또는 제어에 초대하고 접근 권한을 회수합니다.
- 다른 참여자에게 제어권을 넘기거나 해제하고, 소유자로서 되찾을 수 있습니다. 단일 제어자 또는 공동 제어 모드를 선택합니다.
- 일시 중지·재개·취소 기능으로 설치 ISO를 업로드하거나 개인·팀 드라이브에 있는 ISO를 선택합니다.
- 가상 광학 미디어를 삽입·꺼내기 하고 일회성 디스크 부팅을 선택합니다. 미디어를 바꿔도 컴퓨터가 자동 재시작되지는 않습니다.
- 사용 권한이 있는 ARM64 운영체제를 직접 설치하고 선택적인 원격 데스크톱을 별도로 사용합니다. Windows 라이선스는 사용자 책임이며, 사전 정품 인증된 Windows나 일반적인 x86 게스트 지원은 포함되지 않습니다.

<a id="feature-administration"></a>

### 관리, 권한 및 보안

- 역할에서 허용하는 범위 내에서 로컬 멤버를 만들고 계정 상태를 관리하며 암호를 재설정합니다.
- 기본 제공 역할을 할당하고 권한을 확인하며 팀 멤버를 관리합니다. 소유자 관련 중요 작업에는 보호 장치가 적용됩니다.
- 도메인이나 상관관계 ID로 감사 이벤트를 필터링하고 세부 정보를 확인하며 감사 기록 무결성 검증을 요청합니다.
- 관리 작업 공간에서 장비, 앱, 스토리지, 실행 서비스 상태를 확인합니다.
- 외부 AI 제공자와 모델·작업 매핑을 설정하고 자격 증명을 교체하며 제공자를 활성화하거나 비활성화합니다.
- 외부 처리에 대한 명시적 승인을 바탕으로 허용된 로컬·외부 라우팅 정책을 설정합니다. 로컬 AI에는 외부 API 키가 필요하지 않습니다.
- 설치된 모델 프로필, 런타임 버전, 준비 상태와 검증 세부 정보를 확인하세요.
- 검증된 플러그인 패키지를 가져오고 해당 플러그인의 설치, 업그레이드, 활성화·비활성화, 제거를 관리합니다. 보호된 공식 플러그인에는 제한이 있습니다.
- 실행 대기열과 작업을 확인하고 허용된 스케줄링 정책을 조정하며 가능한 작업을 취소합니다.
- 암호화된 저장소와 시작 보호 설정을 확인하세요. 자동 잠금 해제는 로컬 키를 사용하며, 시작 암호문을 활성화하려면 복구 검증과 확인이 필요합니다.

- 공개 Git 저장소를 복제한 뒤 문서에 안내된 소스 설치 명령 하나로 호환되는 새 DGX Spark에 설치합니다.
- 기존 Docker·NVIDIA 환경을 재사용하면서 빌드 도구 준비, 모델·실행 환경 입력 파일 다운로드, 앱 이미지 빌드, 패키징, 설치를 진행합니다.
- 동일한 명령과 작업 디렉터리로 중단된 준비를 재개하며, 검증된 다운로드와 완료된 단계를 재사용합니다.
- 필수 조건 확인, 다운로드만 수행하는 준비, 빌드만 수행하는 패키지 생성을 실행합니다.
- 오프라인 대상에 설치할 수 있는 완전한 이동식 패키지를 준비합니다. 소스로 패키지를 준비하는 단계 자체에는 네트워크 연결이 필요합니다.
- 고정된 입력 파일을 검증하고 필요에 따라 문서에 안내된 대체 출처나 검증된 이동식 캐시를 사용합니다. 타사 미러의 가용성은 보장하지 않습니다.
- 새 장비별 자격 증명과 문서에 명시된 admin/admin 계정을 초기화한 뒤 암호를 변경합니다. 다른 장비의 계정이나 게스트 디스크를 복사하지 않습니다.
- 유지보수 후보, 호환성 확인 결과, 명시적인 실행 계획과 계획 이력을 검토하며 범위가 정해진 롤백·복구 안내를 이용합니다. 임의의 OS·드라이버 자동 업그레이드 기능이 아닙니다.

## NVIDIA DGX Spark란?

NVIDIA DGX Spark는 GB10 Grace Blackwell Superchip을 탑재한 소형 데스크톱 AI 시스템입니다. 128 GB 구성은 20코어 Arm CPU, Blackwell GPU 및 128 GB 통합 시스템 메모리를 제공하며 메모리 대역폭은 273 GB/s입니다. NVIDIA가 명시한 이론상 AI 연산 성능은 희소성을 적용한 FP4 정밀도에서 최대 1 PFLOP입니다.

통합 메모리는 공유 시스템 메모리이며 전용 VRAM이 아닙니다. 사양은 구성에 따라 다르며 이론상 연산 성능이 실제 앱 속도나 동시 사용자 수를 보장하지는 않습니다.

DGX Spark는 연산 능력을, Team AI Box는 로컬 추론, 이미지 생성, OCR, 음성 전사, 번역 및 협업을 위한 공통 인터페이스를 제공합니다. 소스에서 처음 설치할 때는 종속 구성 요소를 다운로드하고 실행 환경을 빌드합니다.

[NVIDIA DGX Spark 공식 하드웨어 사양](https://docs.nvidia.com/dgx/dgx-spark/hardware.html)

Team AI Box는 Weerocks LLC의 독립 프로젝트이며 NVIDIA 제품, 인증 또는 보증을 의미하지 않습니다. 이 프로젝트의 하드웨어 지원 범위는 아래 설치 요구 사항에 따릅니다.

## 새 DGX Spark에 설치

**Ubuntu 24.04 ARM64 기반의 미설치 DGX Spark**, 정상 작동하는 Docker Engine·Compose v2, NVIDIA 드라이버·컨테이너 지원, KVM, Git, Python 3.10+가 필요합니다. 모델·빌드·패키지용 임시 공간 수백 GB를 확보하세요. 기존 업무 데이터 위에 새로 설치하지 마세요.

```sh
git clone https://github.com/weerocksllc/teamaibox.git
cd teamaibox
sudo bash install/from-source.sh
```

위 명령은 **Spark에서** 실행합니다. 모델과 빌드 입력을 다운로드하고 런타임 이미지를 빌드한 뒤 완전한 오프라인 패키지를 만들어 설치합니다. 첫 소스 빌드는 인터넷과 상당한 시간이 필요하며 clone만으로 설치되지 않습니다. 기존 Docker/NVIDIA를 재사용합니다.

### 사전 점검과 재개

`--check`로 사전 점검합니다. 중단되면 `/var/tmp/teamaibox-source-build`를 유지하고 **동일한 명령**을 다시 실행하여 검증된 다운로드와 단계를 재사용하세요. 캐시 삭제나 중복 빌드는 피하세요. 기본은 공식 소스이며 연결이 안 되면 [설치 안내](install/SOURCE-INSTALL.ko.md)의 대체 소스 또는 검증된 캐시/완전한 패키지 전송을 이용합니다. 미러의 가용성은 보장하지 않습니다. 소스 변경 시 새 `--work-dir`를 쓰고 체크포인트를 우회하지 마세요.

```sh
sudo bash install/from-source.sh --check
sudo bash install/from-source.sh
```

### 설치 후

1. 현재 LAN 주소로 `https://<BOX_LAN_IP>/`를 열고 자체 생성 HTTPS 인증서가 본인 기기의 것인지 확인합니다.
2. `admin` / `admin`으로 로그인해 **초기 비밀번호를 변경**하고 일반 계정을 만드세요. 기본 자격 증명을 인터넷에 노출하지 마세요.
3. 각 AI 앱의 준비 완료를 기다리고 프로필 메뉴에서 언어와 테마를 고릅니다.
4. 가상 OS에는 적법한 Windows/Linux ARM64 ISO와 라이선스를 직접 준비합니다. 오프라인 대상에는 완전한 패키지를 먼저 준비하고 [패키지 안내](install/README.ko.md)를 따릅니다. 소스 준비 자체는 온라인 과정입니다.

## 라이선스와 범위

자체 코드와 문서는 MIT이지만 **설치된 모든 바이너리가 MIT은 아닙니다**. 타사 코드, 모델, NVIDIA, 펌웨어, Google, Windows는 각자의 조건을 유지합니다. 저장소에는 모델 가중치, 설치된 게스트 디스크, 로그인 상태, ISO, 설치 패키지가 없습니다. Google 호환은 Play Protect 인증이 아니며 화면 공유는 DRM이나 Apple 인증을 포함하지 않습니다. Windows 10 ARM64 지원을 주장하지 않습니다. 성능·동시 실행은 하드웨어와 작업 부하에 따라 달라집니다.
