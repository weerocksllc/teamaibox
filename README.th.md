**เปลี่ยน NVIDIA DGX Spark ให้เป็นพื้นที่ทำงาน AI ของทีม** ใช้งาน AI ภายในเครื่อง การสร้างภาพ และเครื่องมือเอกสารบน NVIDIA DGX Spark โดย Team AI Box รวมไฟล์ทีม ข้อความ และอุปกรณ์เสมือนไว้ในพื้นที่ทำงานโอเพนซอร์สผ่านเบราว์เซอร์

## ทำไมต้อง Team AI Box?

- **พื้นที่ทำงานเดียว:** อินเทอร์เฟซและบัญชีสอดคล้องกันสำหรับ AI การทำงานร่วมกัน และอุปกรณ์
- **เน้น AI ภายในเครื่อง** รันโมเดลบน Spark และเลือกเชื่อมต่อ API โมเดลภายนอกเมื่อจำเป็น
- **สร้างสำหรับ DGX Spark** ติดตั้งบน Ubuntu ARM64 พร้อมคอนเทนเนอร์ NVIDIA GPU และระบบเสมือน KVM
- **เปิดให้ร่วมปรับปรุง:** โค้ดต้นฉบับใช้ MIT รองรับ 17 ภาษา ธีมสว่าง/มืด และจำการเลือกด้วยตนเอง ค่าเริ่มต้นเป็นภาษาอังกฤษ

### พื้นที่ทำงานและการนำทางประจำวัน

- ใช้พื้นที่ทำงานเดียวในเบราว์เซอร์สำหรับ AI ภายในเครื่อง การทำงานร่วมกันของทีม และอุปกรณ์เสมือนบน DGX Spark เครื่องเดียว
- เรียกดูแอปพลิเคชันตามหมวดหมู่ ค้นหาในรายการแอป และเปิดแอปจากแถบด้านข้าง
- ดูความคืบหน้าการโหลด ความพร้อมใช้งาน และสถานะบริการของแต่ละแอป
- ติดตามงานที่อยู่ในคิว กำลังทำงาน เสร็จสิ้น ล้มเหลว และยกเลิกแล้วในศูนย์งาน พร้อมเปิดผลลัพธ์ที่มีให้
- ดูคำเชิญรับชมการแคสต์ที่รอการตอบรับในเมนูแจ้งเตือน และเปิดแอปแคสต์เพื่อตอบกลับ
- เลือกภาษาหน้าจอได้ 17 ภาษา รวมถึงภาษาอาหรับที่เขียนจากขวาไปซ้าย โดยใช้ภาษาอังกฤษเป็นค่าเริ่มต้นจนกว่าคุณจะเลือกภาษาอื่น
- ใช้ธีมสว่าง มืด หรือตามระบบ โดยภาษาหรือธีมที่เลือกเองจะคงอยู่เมื่อรีเฟรชหน้า ลงชื่อเข้าใช้อีกครั้ง และเปิดแอปต่าง ๆ

<a id="feature-assistant"></a>

### ผู้ช่วย AI และขั้นตอน Agent ที่ควบคุมได้

- เริ่มบทสนทนา บันทึกประวัติ และเปิดบทสนทนาเก่าอีกครั้ง
- เลือกโหมดอัตโนมัติ ตอบคำถาม หรือ Agent สำหรับคำขอปัจจุบัน
- แนบหลายไฟล์ในคำขอเดียวและนำไฟล์แนบออกก่อนส่งได้
- อ่านคำตอบที่ทยอยแสดง หยุดงานที่กำลังทำ และรับสตรีมเหตุการณ์ต่อหลังเชื่อมต่อใหม่
- ตรวจสอบรายละเอียดโมเดล การใช้เครื่องมือ แหล่งข้อมูล และข้อมูลการใช้งานที่ส่งกลับมา พร้อมดาวน์โหลดไฟล์ผลลัพธ์เมื่องานสร้างไฟล์เหล่านั้น
- ตรวจสอบขอบเขตการกระทำของ Agent ที่ต้องยืนยัน แล้วอนุมัติหรือปฏิเสธการกระทำนั้น
- ทำงาน Agent ในสภาพแวดล้อมแยกเฉพาะผู้ใช้พร้อมพื้นที่ทำงานที่เก็บไว้ต่อเนื่อง โดยเครื่องมือและการเข้าถึงเครือข่ายเป็นไปตามนโยบายผู้ดูแลระบบ

<a id="feature-drawing"></a>

### การสร้างภาพด้วย AI

- สร้างภาพจากข้อความคำสั่งด้วยโมเดลภาพที่มีให้ แอปปัจจุบันไม่ใช่โปรแกรมแก้ไขภาพหรือแก้ไขเฉพาะส่วนแบบ inpainting
- เลือกแนวทางการสร้างแบบอัตโนมัติหรือรวดเร็ว เมื่อการตั้งค่าโมเดลที่มีอยู่รองรับ
- เลือกสัดส่วนจัตุรัส แนวนอน หรือแนวตั้ง ขนาดผลลัพธ์ที่รองรับ และค่า seed แบบสุ่มหรือคงที่
- ขอผลลัพธ์เป็น PNG, WebP หรือ JPEG ดูตัวอย่าง และดาวน์โหลดภาพ
- ติดตามคิวและความคืบหน้าการสร้าง ยกเลิกงาน และเรียกคืนงานปัจจุบันเมื่อเปิดหน้าอีกครั้ง
- ตรวจสอบโมเดลที่ใช้จริงและพารามิเตอร์การสร้างที่บันทึกไว้กับผลลัพธ์

<a id="feature-ocr"></a>

### การรู้จำและแก้ไขข้อความ

- อัปโหลด PNG, JPEG, WebP หรือ PDF หรือเลือกไฟล์ที่มีอยู่จากไดรฟ์ทีม
- ระบุภาษาเป็นแนวทาง และรู้จำข้อความ ตาราง Markdown หรือสูตร LaTeX ภายในขีดความสามารถของโมเดลที่เลือก
- ตรวจสอบผลการรู้จำแยกตามหน้าและกลุ่มข้อความ แล้วแก้ไขข้อความที่รู้จำได้ด้วยตนเอง
- ส่งออกเนื้อหาที่ตรวจทานแล้วเป็นข้อความ Markdown หรือ JSON
- ส่งผลการรู้จำที่บันทึกไว้ไปยังแอปแปลภาษา โดยไม่ต้องอัปโหลดและรู้จำต้นฉบับใหม่
- ติดตามและยกเลิกงานรู้จำได้ โมเดลปัจจุบันไม่ให้พิกัดกรอบข้อความหรือคะแนนความมั่นใจ

<a id="feature-transcription"></a>

### การถอดเสียงจากไฟล์และเสียงสด

- เลือกเสียงหรือวิดีโอจากเครื่องหรือไดรฟ์ทีมในรูปแบบ WAV, FLAC, OGG, WebM, MP3, M4A, AIFF หรือ MP4
- ดูหรือฟังตัวอย่างสื่อต้นฉบับ และใช้การตรวจจับภาษาอัตโนมัติหรือระบุภาษาที่รองรับเป็นแนวทาง
- ตรวจดูช่วงข้อความถอดเสียงที่มีเวลาอ้างอิงและแก้ไขข้อความได้
- ส่งออกข้อความ JSON หรือคำบรรยาย SRT และ WebVTT
- ส่งบทถอดเสียงที่บันทึกไว้ไปยังแอปแปลภาษา และติดตามหรือยกเลิกงานถอดเสียงปัจจุบัน
- ถอดเสียงไมโครโฟนแบบสดเมื่อมี HTTPS สิทธิ์จากเบราว์เซอร์ MediaRecorder และบริการเรียลไทม์พร้อมใช้งาน
- ใช้เวลาอ้างอิงระดับคำหรือการแยกผู้พูดเฉพาะกับโปรไฟล์ที่รองรับ โดยขั้นตอนแยกผู้พูดแบบทดลองต้องใช้ไฟล์ WAV

<a id="feature-translation"></a>

### การแปลข้อความ ไฟล์ และสื่อ

- เลือกจากรายการ 60 ภาษาที่โมเดลรองรับ ตรวจจับภาษาต้นทางอัตโนมัติ หรือเลือกและสลับภาษาต้นทางกับปลายทาง ทั้งนี้ไม่ได้รับประกันคุณภาพเท่ากันสำหรับทุกคู่ภาษา
- แปลข้อความที่พิมพ์หรือวาง และเปรียบเทียบช่วงข้อความต้นฉบับกับคำแปล
- อัปโหลดภาพหรือ PDF หรือเลือกจากไดรฟ์ทีม แล้วรู้จำข้อความก่อนแปลเมื่อ OCR พร้อมใช้งาน
- แปลเสียงหรือวิดีโอที่รองรับผ่านการถอดเสียง โดยเก็บเวลาอ้างอิงของแต่ละช่วงเมื่อบริการถอดเสียงพร้อมใช้งาน
- นำผล OCR หรือบทถอดเสียงที่บันทึกไว้กลับมาใช้ และดาวน์โหลดผลลัพธ์ระหว่างทางที่มีให้
- แก้ไขคำแปลและส่งออกเป็นข้อความ Markdown หรือ JSON ส่วนผลลัพธ์เสียงหรือวิดีโอรองรับ SRT และ WebVTT ด้วย
- ติดตามขั้นตอนสกัดข้อความ ถอดเสียง และแปล ยกเลิกงาน และเรียกคืนงานปัจจุบันเมื่อเปิดหน้าอีกครั้ง
- ภาษาที่แปลได้แยกจากภาษาหน้าจอและขอบเขตภาษาของ OCR/ASR การแปล PDF ทำงานกับข้อความ ไม่ได้สร้างเค้าโครงเดิมขึ้นใหม่หรือเป็นเครื่องมือแก้ไข DOCX/XLSX ทั่วไป

<a id="feature-messaging"></a>

### การส่งข้อความในทีม

- ค้นหาเพื่อนร่วมทีม เริ่มแชตส่วนตัว และสร้างแชตกลุ่มที่ตั้งชื่อได้พร้อมสมาชิกที่เลือก
- กรองแชตทั้งหมด แชตที่ยังไม่อ่าน หรือแชตกลุ่ม และค้นหาบทสนทนาหรือข้อความที่คุณมีสิทธิ์เข้าถึง
- ส่งข้อความและไฟล์แนบ พร้อมดาวน์โหลดไฟล์แนบเวอร์ชันต้นฉบับ
- รับข้อความแบบเรียลไทม์ เข้าถึงประวัติแชตเมื่อเชื่อมต่อใหม่ ติดตามตำแหน่งที่อ่านแล้วหรือยังไม่อ่าน และดูสถานะออนไลน์ของสมาชิก
- กด Enter เพื่อส่ง กด Shift+Enter เพื่อขึ้นบรรทัดใหม่ และสลับระหว่างรายการบทสนทนากับแชตบนหน้าจอแคบ
- ลบข้อความออกจากมุมมองของคุณเองหรือล้างประวัติแชตของคุณ โดยไม่ลบบันทึกของผู้ร่วมสนทนาคนอื่น
- ลบแชตออกจากรายการบทสนทนาของคุณโดยไม่ออกจากกลุ่ม และข้อความใหม่อาจทำให้แชตกลับมาปรากฏอีกครั้ง

<a id="feature-drive"></a>

### ไดรฟ์ทีมและการทำงานร่วมกันบนไฟล์

- จัดระเบียบพื้นที่ไฟล์ส่วนตัวและของทีมด้วยโฟลเดอร์และการนำทางตามเส้นทาง
- สลับมุมมองรายการหรือตาราง ดูรายละเอียดไฟล์ ค้นหาไฟล์หรือโฟลเดอร์ และดูการเปลี่ยนแปลงล่าสุด
- อัปโหลดหลายไฟล์ ติดตามความคืบหน้า และยกเลิกการอัปโหลด
- อัปโหลดไฟล์ใหญ่แบบแบ่งส่วนต่อได้โดยเลือกไฟล์เดิมอีกครั้ง โดยเซิร์ฟเวอร์ตรวจสอบส่วนที่อัปโหลดไปแล้ว
- สร้างโฟลเดอร์ เปลี่ยนชื่อ ย้าย หรือคัดลอกไฟล์และโฟลเดอร์
- ดูตัวอย่างภาพ เสียง วิดีโอ ข้อความ และ PDF ที่รองรับ พร้อมดาวน์โหลดไฟล์ ทั้งนี้การเล่นสื่อขึ้นอยู่กับเบราว์เซอร์
- อัปโหลดไฟล์เวอร์ชันใหม่ ดูประวัติเวอร์ชัน และดาวน์โหลดเวอร์ชันก่อนหน้า
- ย้ายรายการไปยังถังขยะและกู้คืนได้
- แชร์ภายในกับสมาชิกหรือทีมด้วยสิทธิ์ดูหรือแก้ไข พร้อมกำหนดวันหมดอายุได้ โดยไม่ใช่การแชร์ลิงก์สาธารณะแบบไม่ระบุตัวตน
- เรียกดูไฟล์และโฟลเดอร์ที่แชร์กับคุณ โดยมีการตรวจสิทธิ์เข้าถึงใหม่ตามสิทธิ์และสมาชิกภาพปัจจุบัน

### การแคสต์ไร้สายที่เข้ากันได้กับ AirPlay

- เริ่มและหยุดตัวรับชั่วคราวสำหรับอุปกรณ์ Apple ที่เข้ากันได้บน LAN เดียวกัน โดยมีชื่อตัวรับและ PIN ของตัวเอง
- เลือกอายุตัวรับ 15, 30, 60 หรือ 120 นาที เมื่อหยุดหรือหมดเวลา การออกอากาศและสิทธิ์รับชมจะสิ้นสุดลง
- จำกัดผู้ชมให้เป็นคุณเอง สมาชิกที่เลือก หรือทีม และเชิญผู้ชมที่สามารถตอบรับหรือปฏิเสธได้
- ดูหน้าจอและฟังเสียงในเบราว์เซอร์ โดยกฎเล่นอัตโนมัติของเบราว์เซอร์อาจกำหนดให้คลิกเพื่อเปิดเสียง

- ดูสถานะตัดการเชื่อมต่อหรือเชื่อมต่อใหม่ และตรวจสิทธิ์รับชมอีกครั้งเมื่อกลับเข้าร่วม
- ต้องมีสภาพแวดล้อมสื่อพร้อมใช้งาน การค้นหาอุปกรณ์บน LAN ที่เข้าถึงได้ และเวอร์ชันเบราว์เซอร์หรืออุปกรณ์ที่เข้ากันได้ การรับชมในเบราว์เซอร์ไม่มีเอาต์พุต HDMI การเล่น DRM/FairPlay หรือการรับรองจาก Apple

## NVIDIA DGX Spark คืออะไร?

NVIDIA DGX Spark เป็นระบบ AI แบบตั้งโต๊ะขนาดเล็กที่ใช้ GB10 Grace Blackwell Superchip รุ่นหน่วยความจำ 128 GB ประกอบด้วย Arm CPU 20 คอร์, Blackwell GPU และหน่วยความจำระบบแบบรวม 128 GB พร้อมแบนด์วิดท์ 273 GB/s NVIDIA ระบุสมรรถนะ AI ทางทฤษฎีสูงสุด 1 PFLOP ที่ความแม่นยำ FP4 โดยใช้ความเบาบางของข้อมูล

หน่วยความจำแบบรวมเป็นหน่วยความจำระบบที่ใช้ร่วมกัน ไม่ใช่ VRAM แยก สเปกแตกต่างกันตามรุ่น สมรรถนะทางทฤษฎีไม่รับประกันความเร็วแอปหรือจำนวนผู้ใช้พร้อมกัน

DGX Spark ให้พลังประมวลผล ส่วน Team AI Box เพิ่มอินเทอร์เฟซร่วมสำหรับการอนุมานภายในเครื่อง การสร้างภาพ OCR การถอดเสียง การแปล และการทำงานร่วมกัน การติดตั้งจากซอร์สครั้งแรกจะดาวน์โหลดส่วนประกอบที่จำเป็นและบิลด์รันไทม์ก่อนตั้งค่า

[ข้อมูลฮาร์ดแวร์อย่างเป็นทางการของ NVIDIA DGX Spark](https://docs.nvidia.com/dgx/dgx-spark/hardware.html)

Team AI Box เป็นโครงการอิสระของ Weerocks LLC ไม่ใช่ผลิตภัณฑ์ การรับรอง หรือการสนับสนุนอย่างเป็นทางการจาก NVIDIA ฮาร์ดแวร์ที่โครงการรองรับระบุไว้ในข้อกำหนดการติดตั้งด้านล่าง

## ติดตั้งบน DGX Spark ใหม่

ใช้ **DGX Spark ที่ยังไม่ติดตั้งผลิตภัณฑ์ พร้อม Ubuntu 24.04 ARM64** มี Docker Engine/Compose v2 ไดรเวอร์และคอนเทนเนอร์ NVIDIA KVM Git และ Python 3.10+ ที่ทำงานได้ เตรียมพื้นที่ชั่วคราวหลายร้อย GB สำหรับโมเดล การสร้าง และแพ็กเกจ ห้ามติดตั้งใหม่ทับข้อมูลเดิม

```sh
git clone https://github.com/weerocksllc/teamaibox.git
cd teamaibox
sudo bash install/from-source.sh
```

รันคำสั่ง **บน Spark** สคริปต์ดาวน์โหลดโมเดลและอินพุต สร้างอิมเมจและแพ็กเกจออฟไลน์ฉบับเต็ม แล้วติดตั้ง การสร้างครั้งแรกต้องใช้อินเทอร์เน็ตและเวลา clone อย่างเดียวยังไม่พร้อมใช้ ระบบใช้ Docker/NVIDIA เดิม

### ตรวจสอบก่อนและทำต่อ

`--check` ตรวจข้อกำหนด หากหยุดกลางทางให้เก็บ `/var/tmp/teamaibox-source-build` แล้วรัน **คำสั่งเดิม** เพื่อใช้ไฟล์และขั้นตอนที่ตรวจแล้วต่อ อย่าลบแคชหรือสร้างซ้ำพร้อมกัน ค่าเริ่มต้นเป็นแหล่งทางการ หากเข้าถึงไม่ได้ให้อ่าน [คู่มือ](install/SOURCE-INSTALL.th.md) เรื่องแหล่งอื่นหรือย้ายแคช/แพ็กเกจที่ตรวจสอบแล้ว มิเรอร์ไม่รับประกันความพร้อม หากโค้ดเปลี่ยนให้ใช้ `--work-dir` ใหม่ ไม่ข้ามการตรวจสอบ

```sh
sudo bash install/from-source.sh --check
sudo bash install/from-source.sh
```

### หลังติดตั้ง

1. เปิด `https://<BOX_LAN_IP>/` ด้วย IP ใน LAN ปัจจุบัน และยืนยันว่าใบรับรอง HTTPS ภายในเป็นของอุปกรณ์ตนเอง
2. เข้าสู่ระบบด้วย `admin` / `admin` แล้ว **เปลี่ยนรหัสผ่านเริ่มต้น** และสร้างบัญชีทั่วไป อย่าเปิดข้อมูลเริ่มต้นนี้สู่อินเทอร์เน็ต
3. รอแต่ละแอปพร้อม แล้วเลือกภาษา/ธีมในโปรไฟล์
4. จัดเตรียม ISO ARM64 Windows/Linux และสิทธิ์ใช้งานเอง สำหรับเครื่องออฟไลน์ต้องเตรียมแพ็กเกจครบก่อนและทำตาม [คู่มือ](install/README.th.md) การเตรียมจากซอร์สต้องออนไลน์

## สิทธิ์ใช้งานและข้อจำกัด

โค้ดและเอกสารต้นฉบับใช้ MIT **ไม่ใช่ไบนารีทั้งหมดที่ติดตั้ง** โค้ดภายนอก โมเดล NVIDIA เฟิร์มแวร์ Google และ Windows มีเงื่อนไขของตน Git ไม่รวมค่าน้ำหนัก ดิสก์ระบบที่ติดตั้งแล้ว สถานะล็อกอิน ISO หรือแพ็กเกจ ความเข้ากันได้กับ Google ไม่เท่ากับการรับรอง Play Protect การแชร์หน้าจอไม่รวม DRM หรือการรับรอง Apple ไม่อ้างว่ารองรับ Windows 10 ARM64 ประสิทธิภาพและการทำงานพร้อมกันขึ้นอยู่กับฮาร์ดแวร์และภาระงาน
