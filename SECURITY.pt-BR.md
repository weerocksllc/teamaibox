# Relatórios de segurança

Por favor, relate suspeitas de vulnerabilidades em particular para **teamaibox@weerocks.llc**. Inclui versão afetada, reprodução mínima, impacto e registros editados. Não coloque credenciais, conteúdo de clientes ou explore detalhes em questões públicas. Solicite um canal de transferência seguro apropriado antes de enviar arquivos confidenciais. Nenhuma garantia de tempo de resposta ou certificação de segurança independente é reivindicada.

Novas instalações off-line atualmente usam o administrador de inicialização documentado `admin` / `admin`; altere essa senha antes de expor o dispositivo a usuários ou a uma rede não confiável. Esta é uma credencial inicial pública, não um segredo a ser escondido em uma lista de permissões de scanner. Nenhuma conta de usuário comum é criada automaticamente. A alteração deste comportamento de integração está fora desta alteração de licenciamento.

## Revisão da fonte/histórico

Consulte [o limite de privacidade de fonte pública](docs/open-source/SOURCE-PRIVACY.pt-BR.md) para dados excluídos, revisão de histórico e responsabilidades de rotação de credenciais.

Execute o scanner local fixado conforme descrito em [preparação da versão](docs/open-source/RELEASING.pt-BR.md). Os relatórios são privados, editados e nunca enviados para um serviço de verificação externo. Se uma credencial real aparecer no histórico privado, a exclusão do HEAD não é revogação. Revogar/rodar com o proprietário; reescrever ou excluir o histórico precisa de autorização separada. As etiquetas de entrega originais não são movidas para higienização.

O candidato de fonte pública é uma exportação de arquivo recente sem `.git`, evidências privadas, instantâneos de dispositivos, dados de convidados ou binários restritos. **Não** simplesmente altere a visibilidade deste repositório de desenvolvimento ou envie publicamente suas referências antigas.
