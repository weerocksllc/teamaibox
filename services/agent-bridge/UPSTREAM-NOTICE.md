# OpenCode native contract

`opencode-native-contract.json` contains endpoint metadata derived from
`packages/sdk/openapi.json` at upstream commit
`810c0eba1a7348036f8bdf61e6632d0c36c6876c` (v1.19.5).
Source: https://github.com/anomalyco/opencode

No OpenCode Web GUI, Solid components or upstream UI state code are included
in this integration. The Team AI Box frontend is implemented in React.
