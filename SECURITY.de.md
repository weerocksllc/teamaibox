# Sicherheitsberichte

Bitte melden Sie vermutete Schwachstellen privat an **teamaibox@weerocks.llc**. Berücksichtigen Sie die betroffene Version, die minimale Reproduktion, die Auswirkungen und die geschwärzten Protokolle. Geben Sie keine Anmeldeinformationen, Kundeninhalte oder Exploit-Details in öffentlichen Ausgaben ab. Fragen Sie nach einem geeigneten sicheren Übertragungskanal, bevor Sie vertrauliche Dateien senden. Es wird keine Reaktionszeitgarantie oder unabhängige Sicherheitszertifizierung beansprucht.

Neue Offline-Installationen verwenden derzeit den dokumentierten Bootstrap-Administrator `admin` / `admin`; Ändern Sie dieses Kennwort, bevor Sie die Appliance Benutzern oder einem nicht vertrauenswürdigen Netzwerk zugänglich machen. Dabei handelt es sich um eine öffentliche Erstanmeldeinformation und nicht um ein Geheimnis, das in einer Scanner-Zulassungsliste versteckt werden sollte. Es wird kein gewöhnliches Benutzerkonto automatisch erstellt. Die Änderung dieses Onboarding-Verhaltens liegt außerhalb dieser Lizenzänderung.

## Quellen-/Geschichtsüberprüfung

Informationen zu ausgeschlossenen Daten, Verlaufsüberprüfung und Verantwortlichkeiten für die Rotation von Anmeldeinformationen finden Sie in [den Datenschutzgrenzen für öffentliche Quellen](docs/open-source/SOURCE-PRIVACY.de.md).

Führen Sie den angehefteten lokalen Scanner aus, wie in [Release-Vorbereitung](docs/open-source/RELEASING.de.md) beschrieben. Berichte sind privat, redigiert und werden niemals auf einen externen Scandienst hochgeladen. Wenn ein echter Berechtigungsnachweis im privaten Verlauf erscheint, ist das Löschen aus HEAD kein Widerruf. Widerrufen/Rotieren mit dem Eigentümer; Das Umschreiben oder Löschen des Verlaufs erfordert eine separate Autorisierung. Originale Lieferetiketten werden zur Desinfektion nicht verschoben.

Der öffentliche Quellkandidat ist ein frischer Dateiexport ohne `.git`, private Beweise, Geräte-Snapshots, Gastdaten oder eingeschränkte Binärdateien. Ändern Sie **nicht** einfach die Sichtbarkeit dieses Entwicklungs-Repositorys oder veröffentlichen Sie seine alten Refs nicht öffentlich.
