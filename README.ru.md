## Почему Team AI Box

- **Единое пространство:** общий интерфейс и учётные записи для ИИ, совместной работы и устройств.
- **Локальный ИИ в приоритете.** Запускайте модели на своём Spark и при необходимости подключайте API внешних моделей.
- **Создан для DGX Spark.** Устанавливайте на Ubuntu ARM64 с GPU-контейнерами NVIDIA и виртуализацией KVM.
- **Открыт для улучшений:** собственный код MIT, 17 языков, светлая/тёмная тема, сохранение ручного выбора. По умолчанию — английский.

<a id="feature-workspace"></a>

### Рабочее пространство и повседневная навигация

- Работайте с локальным ИИ, командными инструментами и виртуальными устройствами в едином браузерном пространстве на одном DGX Spark.
- Просматривайте приложения по категориям, ищите их в каталоге и открывайте из боковой панели.
- Просматривайте ход загрузки, доступность и состояние сервисов каждого приложения.
- Отслеживайте ожидающие, выполняемые, завершённые, неудачные и отменённые задания в центре задач; открывайте доступные результаты.
- Просматривайте ожидающие ответа приглашения на трансляцию в меню уведомлений и открывайте приложение трансляции, чтобы ответить.
- Выбирайте из 17 языков интерфейса, включая арабский с письмом справа налево; английский используется по умолчанию, пока вы не выберете другой язык.
- Используйте светлую, тёмную или системную тему; выбранные вручную язык и тема сохраняются при обновлении страницы, повторном входе и переходе между приложениями.

<a id="feature-assistant"></a>

### ИИ-ассистент и контролируемая работа агента

- Начинайте диалоги, сохраняйте их историю и возвращайтесь к предыдущим обсуждениям.
- Выбирайте для текущего запроса режим «Автоматически», «Ответ» или «Агент».
- Прикрепляйте несколько файлов к запросу и удаляйте вложения до отправки.
- Читайте ответы по мере генерации, останавливайте активное выполнение и возобновляйте его поток событий после переподключения.
- Просматривайте возвращённые сведения о модели, действия инструментов, источники и использование ресурсов; скачивайте артефакты, если они созданы при выполнении.
- Просматривайте объём действия агента, требующего подтверждения, и разрешайте либо отклоняйте это действие.
- Выполняйте задачи агента в отдельной для каждого пользователя песочнице с постоянным рабочим пространством; доступ к инструментам и сети определяется политикой администратора.

<a id="feature-drawing"></a>

### Генерация изображений с ИИ

- Генерируйте изображение по текстовому описанию с помощью доступной модели; текущее приложение не является редактором изображений или инструментом перерисовки отдельных областей.
- Выбирайте автоматический или быстрый вариант генерации, если это поддерживает конфигурация доступной модели.
- Выбирайте квадратные, горизонтальные или вертикальные пропорции, поддерживаемые размеры результата и случайное или фиксированное зерно генерации.
- Запрашивайте результат в PNG, WebP или JPEG, просматривайте и скачивайте изображение.
- Следите за очередью и ходом генерации, отменяйте задания и восстанавливайте текущую задачу после повторного открытия страницы.
- Просматривайте фактически использованную модель и параметры генерации, записанные вместе с результатом.

<a id="feature-ocr"></a>

### Распознавание и исправление текста

- Загружайте PNG, JPEG, WebP или PDF либо выбирайте существующий файл на командном диске.
- Укажите предполагаемый язык и распознавайте текст, таблицы Markdown или формулы LaTeX в пределах возможностей выбранной модели.
- Проверяйте результат распознавания по страницам и текстовым блокам, затем вручную исправляйте распознанный текст.
- Экспортируйте проверенное содержимое как текст, Markdown или JSON.
- Передавайте сохранённый результат распознавания в «Перевод» без повторной загрузки и распознавания исходного файла.
- Отслеживайте и отменяйте задания распознавания. Текущая модель не выдаёт координаты ограничивающих рамок или оценки уверенности.

<a id="feature-transcription"></a>

### Расшифровка записанной и живой речи

- Выбирайте аудио или видео с локального устройства или командного диска: WAV, FLAC, OGG, WebM, MP3, M4A, AIFF или MP4.
- Просматривайте исходную запись и используйте автоматическое определение языка либо указывайте поддерживаемый язык.
- Проверяйте фрагменты расшифровки с временными метками и редактируйте их текст.
- Экспортируйте текст, JSON или субтитры SRT и WebVTT.
- Передавайте сохранённую расшифровку в «Перевод», отслеживайте или отменяйте текущую задачу расшифровки.
- Расшифровывайте речь с микрофона в реальном времени при наличии HTTPS, разрешения браузера, MediaRecorder и службы реального времени.
- Используйте временные метки отдельных слов или разделение по говорящим только с поддерживающими их профилями; экспериментальный сценарий разделения по говорящим требует входной файл WAV.

<a id="feature-translation"></a>

### Перевод текста, файлов и медиазаписей

- Выбирайте из каталога 60 языков, поддерживаемых моделью, определяйте исходный язык автоматически либо задавайте и меняйте местами исходный и целевой языки. Одинаковое качество для всех языковых пар не гарантируется.
- Переводите введённый или вставленный текст и сравнивайте исходные и переведённые фрагменты.
- Загружайте изображение или PDF либо выбирайте файл на командном диске; при готовности OCR распознавайте его текст перед переводом.
- Переводите поддерживаемые аудио- и видеозаписи через расшифровку с сохранением временных границ фрагментов, когда служба расшифровки готова.
- Повторно используйте сохранённые результаты OCR и расшифровки, скачивайте доступные промежуточные результаты.
- Редактируйте перевод и экспортируйте текст, Markdown или JSON; результаты для аудио и видео также поддерживают SRT и WebVTT.
- Следите за этапами извлечения, расшифровки и перевода, отменяйте работу и восстанавливайте текущую задачу после повторного открытия страницы.
- Набор языков перевода не совпадает с наборами языков интерфейса и OCR/ASR. Перевод PDF работает с текстом, не воссоздаёт исходную вёрстку и не является универсальным редактором DOCX/XLSX.

<a id="feature-messaging"></a>

### Командные сообщения

- Находите коллег, начинайте личные диалоги и создавайте именованные групповые чаты с выбранными участниками.
- Отбирайте все, непрочитанные или групповые чаты и ищите в доступных вам диалогах и сообщениях.
- Отправляйте текст и файловые вложения; скачивайте исходную версию прикреплённого файла.
- Получайте сообщения в реальном времени, восстанавливайте историю после переподключения, отслеживайте прочитанное и непрочитанное, видьте присутствие участников.
- Отправляйте сообщение клавишей Enter, добавляйте новую строку сочетанием Shift+Enter и переключайтесь между списком диалогов и чатом на узких экранах.
- Удаляйте сообщение только из своего представления или очищайте собственную историю чата; записи других участников не удаляются.
- Удаляйте чат из своего списка диалогов без выхода из группы; новое сообщение может вернуть его в список.

<a id="feature-drive"></a>

### Командный диск и совместная работа с файлами

- Организуйте личные и командные файловые пространства с папками и навигационной цепочкой.
- Переключайтесь между списком и сеткой, просматривайте сведения о файлах, ищите файлы и папки, следите за недавними изменениями.
- Загружайте несколько файлов, следите за ходом загрузки и отменяйте её.
- Возобновляйте загрузку большого файла по частям, повторно выбрав тот же файл; сервер проверяет загруженные части.
- Создавайте папки, переименовывайте, перемещайте или копируйте файлы и папки.
- Предварительно просматривайте поддерживаемые изображения, аудио, видео, текст и PDF, скачивайте файлы; воспроизведение зависит от браузера.
- Загружайте новую версию файла, просматривайте историю версий и скачивайте предыдущие версии.
- Перемещайте объекты в корзину и восстанавливайте их.
- Предоставляйте внутренний доступ участникам или командам с правом просмотра либо редактирования и необязательным сроком действия; анонимных публичных ссылок нет.
- Просматривайте файлы и папки, которыми с вами поделились; доступ повторно проверяется по действующим правам и членству в команде.

<a id="feature-casting"></a>

### Беспроводная трансляция, совместимая с AirPlay

- Запускайте и останавливайте временный приёмник для совместимых устройств Apple в той же локальной сети, с собственными именем и PIN-кодом.
- Выбирайте срок работы приёмника: 15, 30, 60 или 120 минут; остановка или истечение срока прекращает его объявление в сети и доступ к просмотру.
- Ограничивайте просмотр собой, выбранными участниками или командой; приглашайте зрителей, которые могут принять или отклонить приглашение.
- Смотрите экран и слушайте звук в браузере; правила автовоспроизведения могут потребовать нажатия для включения звука.
- Просматривайте и удаляйте подключённых зрителей; администратор может остановить сеанс, не получая права смотреть закрытое содержимое.
- Следите за состояниями отключения и переподключения; при повторном присоединении право просмотра проверяется заново.
- Требуются готовая среда обработки медиаданных, доступное обнаружение в локальной сети и совместимые версии браузера и устройства. Просмотр в браузере не предоставляет вывод HDMI, воспроизведение DRM/FairPlay или сертификацию Apple.

<a id="feature-phones"></a>

### Виртуальные Android-телефоны с сохранением данных

- Создавайте независимые Android-телефоны из установленных системных профилей, сохраняя приложения и данные каждого телефона между сеансами.
- Запускайте, выключайте, перезапускайте, переименовывайте и явно удаляйте отдельные телефоны.
- Управляйте Android с помощью клавиатуры и указателя, кнопок «Назад», «Домой», «Недавние приложения» и регулировки громкости.
- Используйте звук и полноэкранный режим, переподключайтесь или переносите активное подключение телефона на другую страницу.
- Загружайте файлы на телефон и скачивайте их из его папки передачи Team AI Box.
- Устанавливайте собственные APK после подтверждения; разрешения приложений Android не выдаются скрытно.
- Подавайте изображение, видео или камеру браузера на виртуальную камеру при наличии поддержки; физические USB-камеры и сетевые источники дополнительно требуют настройки и разрешений администратора.
- Временно разрешайте отладку ADB только для выбранного устройства через краткоживущий ретранслятор, используя стандартные инструменты ADB и клиент ретрансляции Node.js.
- По запросу просматривайте частоту кадров, потери пакетов и время прохождения сигнала туда и обратно; это не гарантия сквозной задержки.
- Выбирайте системный профиль Google Play только при наличии его ресурсов; доступность не означает сертификацию Play Protect и не гарантирует работу каждого приложения Android.

<a id="feature-computers"></a>

### Виртуальные компьютеры Windows и Linux

- Создавайте независимые компьютеры ARM64 с Windows/Linux, выбирая число процессоров, объём памяти и диска.
- Запускайте компьютер, штатно завершайте его работу и удаляйте остановленный компьютер после явного подтверждения.
- Открывайте виртуальный монитор в браузере для просмотра прошивки, загрузки, установки и экранов ОС без предварительного входа в удалённый рабочий стол.
- Используйте клавиатуру, указатель, звук, полноэкранный режим и управление переподключением.
- Открывайте один виртуальный компьютер в нескольких вкладках или окнах браузера.
- Приглашайте коллег смотреть монитор или управлять им и отзывайте их доступ.
- Передавайте управление другому участнику, освобождайте его или забирайте обратно как владелец; выбирайте единоличное или совместное управление.
- Загружайте установочный ISO с паузой, продолжением и отменой либо выбирайте существующий ISO на личном или командном диске.
- Подключайте и извлекайте виртуальный оптический носитель, выбирайте однократную загрузку с диска; смена носителя не перезапускает компьютер автоматически.
- Устанавливайте собственную разрешённую к использованию ОС ARM64 и отдельно используйте необязательный удалённый рабочий стол. За лицензию Windows отвечаете вы; заранее активированная Windows и общая поддержка гостевых x86-систем не включены.

<a id="feature-administration"></a>

### Администрирование, права и безопасность

- Создавайте локальных участников, управляйте состоянием учётных записей и сбрасывайте пароли в пределах своей роли.
- Назначайте встроенные роли, просматривайте права и управляйте составом команд с защитными ограничениями для операций владельца.
- Фильтруйте события аудита по области или идентификатору корреляции, просматривайте подробности и запрашивайте проверку целостности истории аудита.
- Просматривайте состояние устройства, приложений, хранилища и служб выполнения в пространстве администрирования.
- Настраивайте внешних провайдеров ИИ и соответствия моделей и операций, заменяйте учётные данные, включайте или отключайте провайдеров.
- Задавайте разрешённые политики локальной и внешней маршрутизации с явным одобрением внешней обработки; локальному ИИ не нужен внешний ключ API.
- Просматривайте установленные профили моделей, версии сред выполнения, готовность и сведения о проверке.
- Импортируйте проверенные пакеты плагинов и управляйте установкой, обновлением, включением, отключением и удалением разрешённых плагинов; защищённые официальные плагины имеют ограничения.
- Просматривайте очереди и задания выполнения, изменяйте разрешённые политики планирования и отменяйте задания, для которых это допускается.
- Просматривайте настройки зашифрованного хранилища и защиты при запуске. Автоматическая разблокировка использует локальный ключ; для включения парольной фразы при запуске необходимы проверка восстановления и подтверждение.

## Что такое NVIDIA DGX Spark?

NVIDIA DGX Spark — компактная настольная ИИ-система на базе GB10 Grace Blackwell Superchip. Конфигурация 128 GB объединяет 20-ядерный процессор Arm, GPU Blackwell и 128 GB унифицированной системной памяти с пропускной способностью 273 GB/s. NVIDIA заявляет до 1 PFLOP теоретической производительности ИИ при точности FP4 с использованием разреженности.

Унифицированная память — общая системная память, а не выделенная VRAM. Характеристики зависят от конфигурации; теоретическая мощность не гарантирует скорость приложений или число одновременных пользователей.

DGX Spark обеспечивает вычисления. Team AI Box добавляет общий интерфейс для локального инференса, генерации изображений, OCR, транскрипции, перевода и совместной работы. При первой установке из исходников загружаются зависимости и собирается среда выполнения.

[Официальные характеристики NVIDIA DGX Spark](https://docs.nvidia.com/dgx/dgx-spark/hardware.html)

Team AI Box — независимый проект Weerocks LLC, а не продукт, сертификация или рекомендация NVIDIA. Поддерживаемое оборудование определяется требованиями к установке ниже.

## Установка на новый DGX Spark

Нужен **чистый DGX Spark с Ubuntu 24.04 ARM64**, рабочими Docker Engine/Compose v2, драйверами и контейнерами NVIDIA, KVM, Git и Python 3.10+. Оставьте несколько сотен ГБ временного места для моделей, сборки и пакета. Не устанавливайте заново поверх рабочих данных.

```sh
git clone https://github.com/weerocksllc/teamaibox.git
cd teamaibox
sudo bash install/from-source.sh
```

Выполните команды **на Spark**. Скрипт загрузит исходные материалы и модели, соберёт образы, создаст полный автономный пакет и установит его. Первая сборка требует Интернета и времени; clone не означает установку. Docker/NVIDIA используются повторно.

### Проверка и продолжение

`--check` проверяет условия. После прерывания сохраните `/var/tmp/teamaibox-source-build` и повторите **ту же команду**: проверенные загрузки и этапы используются повторно. Не удаляйте кэш и не запускайте конкурирующие сборки. По умолчанию источники официальные. При недоступности используйте варианты из [инструкции](install/SOURCE-INSTALL.ru.md) либо перенесите проверенный кэш/полный пакет. Доступность зеркал не гарантируется. Для изменённого кода нужен новый `--work-dir`, а не обход проверок.

```sh
sudo bash install/from-source.sh --check
sudo bash install/from-source.sh
```

### После установки

1. Откройте `https://<BOX_LAN_IP>/` по текущему LAN-адресу и проверьте, что локальный HTTPS-сертификат принадлежит вашему устройству.
2. Войдите как `admin` / `admin`, **смените начальный пароль**, создайте обычные аккаунты. Не выставляйте исходные данные входа в Интернет.
3. Дождитесь готовности приложений и выберите язык/тему в профиле.
4. Предоставьте законные ARM64 ISO и лицензии Windows/Linux. Для автономной машины сначала подготовьте полный пакет по [инструкции](install/README.ru.md); подготовка из исходников требует сети.
