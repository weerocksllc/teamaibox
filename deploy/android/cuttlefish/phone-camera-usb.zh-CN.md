# 使用盒子的 USB 摄像头

虚拟手机使用插在**同一台 Team AI Box**上的 USB 摄像头。
浏览器所在电脑的摄像头属于“浏览器摄像头”，不是这里的 USB 设备。

## 操作步骤

1. 将摄像头插入盒子，管理员在设备设置中允许相应成员使用。
2. 打开自己的虚拟手机，进入“摄像头”设置。
3. 选择“盒子 USB 摄像头”，从实际设备列表中选定一只摄像头。
4. 启动输入，再打开 Android 内的相机应用。

无需重装手机，也不需要把整个 USB 控制器交给手机。多个设备时必须明确选择；
设备忙时不能抢占其他应用。拔出再插入后，应重新读取设备列表并确认选择，
不能悄悄换成另一只摄像头。

## 实现边界

本机 USB 摄像头 → 受限采集进程 → 该手机的帧输入 → virtio-media →
Android V4L2 Camera HAL → Camera2。采集器取得已授权的精确设备句柄，
不向浏览器或 Android 暴露任意宿主路径。

摄像头实际支持的格式、分辨率和帧率来自设备查询；转换应保持画面比例。
采集器与手机一起计入本机资源预算。停止、撤权、断开或更换来源后，旧帧被清空，
设备被释放；服务恢复不应自动重新开启已经停止的私人采集。

USB 摄像头不自动变成 Android 麦克风。需要声音时应使用单独提供的麦克风能力。

## 排查

- 列表为空：检查物理连接、系统识别和成员授权。
- 设备忙：先在占用它的应用中停止采集。
- Android 画面未更新：确认网页输入状态和当前手机运行状态，再重开相机应用。
- 拔插后无法恢复：刷新设备目录，重新选择；不要删除或重建手机。

具体版本的验收结果保留在独立的验证记录中，本指南不把早期隔离测试当作当前版本的完成证明。
