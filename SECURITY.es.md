# Informes de seguridad

Informe las vulnerabilidades sospechosas de forma privada a **teamaibox@weerocks.llc**. Incluya la versión afectada, la reproducción mínima, el impacto y los registros redactados. No incluya credenciales, contenido de clientes ni explote detalles en publicaciones públicas. Solicite un canal de transferencia seguro adecuado antes de enviar archivos confidenciales. No se afirma ninguna garantía de tiempo de respuesta ni certificación de seguridad independiente.

Las nuevas instalaciones fuera de línea actualmente utilizan el administrador de arranque documentado `admin` / `admin`; cambie esa contraseña antes de exponer el dispositivo a usuarios o a una red que no sea de confianza. Esta es una credencial inicial pública, no un secreto que deba ocultarse en una lista de permitidos del escáner. Ninguna cuenta de usuario normal se crea automáticamente. Cambiar este comportamiento de incorporación está fuera de este cambio de licencia.

## Fuente/revisión histórica

Consulte [el límite de privacidad de la fuente pública](docs/open-source/SOURCE-PRIVACY.es.md) para conocer los datos excluidos, la revisión del historial y las responsabilidades de rotación de credenciales.

Ejecute el escáner local anclado como se describe en [preparación de lanzamiento](docs/open-source/RELEASING.es.md). Los informes son privados, están redactados y nunca se cargan a un servicio de escaneo externo. Si una credencial real aparece en el historial privado, la eliminación de HEAD no es una revocación. Revocarlo/rotarlo con el propietario; reescribir o eliminar el historial necesita una autorización por separado. Las etiquetas de entrega originales no se mueven para su desinfección.

La fuente pública candidata es una exportación de archivo nueva sin `.git`, evidencia privada, instantáneas del dispositivo, datos de invitados o archivos binarios restringidos. **No** simplemente cambie la visibilidad de este repositorio de desarrollo ni publique sus antiguas referencias.
