# Escopo de direitos autorais e procedência

MIT é aplicado por instrução do proprietário do projeto às contribuições originais de Team AI Box atribuídas a Weerocks LLC. Os nomes dos autores do Git são de origem útil, e não prova de emprego, atribuição ou autoridade para licenciar trabalho de terceiros. O histórico local revisado possui 20 commits acessíveis e duas identidades de autor; detalhes de contato pessoal do autor e registros de desenvolvimento privados não são copiados para a exportação de origem. Nenhuma atribuição assinada ou permissão adicional do fornecedor é inferida desse histórico.
