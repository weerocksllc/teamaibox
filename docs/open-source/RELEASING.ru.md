# Освободите границы

## Отдельные артефакты

1. **MIT кандидат в исходный код**: исходный код, текущие спецификации, проверенные инструменты сборки/тестирования и примечания; никакой истории Git или свидетельств из частных лабораторий.
2. **Сторонний материал**: точный исходный код/бинарные файлы/модели с собственной лицензией и указанием авторства. Обязательства по источнику с авторским левом передаются вместе с двоичными файлами.
3. **Полный пакет автономного устройства**: создан `install/`; не лицензируется автоматически для публичного распространения. Компоненты GMS, HunyuanOCR, NVIDIA и гостевые лицензии/микропрограммы требуют проверки конкретного артефакта. Не публикуйте частный пакет, наборы моделей или изображения, для которых выполнен вход в систему, под ярлыком MIT.
4. **Маркетинговый веб-сайт**: `website/`, включая шаблоны статей, контент, ресурсы дизайна, аналитику и конфигурацию развертывания, остается в частном репозитории `weerocksllc/teamaibox.com` GitHub. GitLab — это исторический архив, а не хранилище разработки веб-сайтов. Веб-сайт не является частью общедоступного распространения исходного кода продукта. Пользовательский интерфейс браузера устройства в `apps/` остается частью продукта с открытым исходным кодом.

Сценарии исторического развертывания, восстановления и записи доказательств на одном устройстве не являются инструментами многократного использования. Политика выпуска исключает устаревшие сценарии и снимки; не восстанавливайте их из личного архива. Для сохраненных инструментов требуются явные цели, указанные оператором, а не хосты, учетные записи, контейнеры или файлы доказательств разработчика. Запустите дополнительное конфиденциальное сканирование, а также Gitleaks: идентификаторы устройств, идентификаторы контейнеров, хэши GSF и имена личных учетных записей проверяют метаданные, даже если они не являются пригодными для использования учетными данными для входа. Очистка общедоступной истории требует явного разрешения владельца и никогда не должна перезаписывать частный архив или его теги доставки. После авторизованной перезаписи используйте новый общедоступный клон, а не объединяйте устаревшую историю обратно в поддерживаемый репозиторий.

Внутренний репозиторий разработки и его теги остаются нетронутыми. Его доступная история содержит старые записи о развертывании и устаревшие собственные ресурсы SDK; его нельзя публиковать в неизменном виде. Свежее экспортированное дерево обеспечивает публичную отправную точку, не переписывая исходную историю доставки.

## Местный препарат

Используйте **Gitleaks 8.30.1**, скачанный с официального релиза GitHub, и проверьте его контрольную сумму. Инструмент аудита никогда не устанавливает системные пакеты и не загружает данные. Частный вывод игнорируется `.runtime/open-source-audit/`, а не публичный пиар.

```sh
python3 tools/open_source_release.py baseline --output .runtime/open-source-audit/before.json
python3 tools/open_source_release.py scan --gitleaks /path/to/gitleaks --output .runtime/open-source-audit/review
python3 tools/open_source_sensitive.py --output .runtime/open-source-audit/project-review.json
python3 tools/open_source_inventory.py
python3 tools/open_source_release.py export --gitleaks /path/to/gitleaks --output .runtime/open-source-audit/source-candidate
```

Выходами должны быть новые пути; инструменты никогда не перезаписывают предыдущих кандидатов. Просмотрите отредактированные локации, а не только количество. Отдельно документируйте синтетические приспособления, общедоступные учетные данные начальной загрузки, ложные срабатывания идентификаторов и фактические/возможные частные учетные данные. Сканирование шаблонов не позволяет проверить учетные данные или снимки экрана OCR. Двоичные артефакты исключены и не объявлены отсканированными как чистые. Экспортер исходного кода допускает только файлы, известные Git, и явные неотслеживаемые входные данные в [release-policy.json](release-policy.json). Новые неотслеживаемые входные данные требуют проверки. Он отклоняет символические ссылки и обход путей и генерирует для каждого файла SHA-256 плюс исключения. `website/` всегда исключается, даже если он отслеживается или указан как неотслеживаемый вход. Никогда не копируйте каталог `.git` частного репозитория в общедоступную кассу. Перед публикацией убедитесь, что дерево и все доступные общедоступные коммиты не содержат файлов веб-сайта; удаление файлов в более позднем коммите не удаляет старую историю.

Дополнительная проверка включает в себя доступные сообщения фиксации/тегирования, учетные данные с низкой энтропией и литералы входа в систему, идентификаторы устройств и адреса разработки. Испытания не освобождаются автоматически: объясните, почему каждое оставленное приспособление является синтетическим. Известные частные значения могут быть предоставлены с помощью `--denylist` как внешний массив JSON из записей `{id, value, word?}`. Используйте непрозрачные, неконфиденциальные идентификаторы; держите этот файл вне проверки исходного кода. В отчетах показаны местоположения и хэши, а не значения. Соответствие известного маркера приводит к сбою проверки. Используйте `--scope worktree` во время уборки; перед публикацией проверьте `--scope all` в новом репозитории выпусков без родительских элементов. Не публикуйте старую историю или частные обзорные отчеты.

Единственное намеренное значение по умолчанию администратора фабрики — `admin / admin`; измените его во время развертывания. Инструменты развертывания/тестирования браузера должны получать учетные данные существующей учетной записи через защищенный локальный ввод. Вновь созданные учетные записи дымового тестирования используют случайные учетные данные и отключаются во время очистки. Неудачная очистка — это провал теста, а не успешный запуск. Резкое завершение процесса может помешать очистке; операторы должны сверить свои временные счета после такого перерыва. Ни в одном общедоступном документе не утверждается, что сертификат тестирования в настоящее время действителен.

Только поддерживаемая точка входа `install/` является путем чистой установки устройства. Оценка владения компонентом находится в [OWNERSHIP.md](OWNERSHIP.ru.md).

Ни одна команда здесь не запускает Git, не меняет видимость, не перезаписывает историю, не меняет текущие учетные данные, не меняет устройство и не предоставляет сторонним правам на распространение. Для публичного выпуска требуется явно выбранное общедоступное место назначения и окончательная проверка артефакта. Сохраните `delivery-2026-10-22` в частном репозитории.
