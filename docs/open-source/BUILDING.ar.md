# ابني المصدر

القطعة الأثرية العامة هي مصدر، وليست صورة جهاز تم إنشاؤها مسبقًا دون اتصال بالإنترنت. قد يقوم الإصدار المصدر بتنزيل التبعيات؛ يبقى التثبيت باستخدام الحزمة الكاملة المعدة دون اتصال بالإنترنت. لا تحتاج أي من العمليتين إلى ViKey SDK أو مفتاح USB.

لتثبيت الجهاز بالكامل، ابدأ بالجذر [البدء السريع](../../README.ar.md#install) و[مثبت المصدر](../../install/SOURCE-INSTALL.ar.md): يقوم `sudo bash install/from-source.sh` بالتنزيل والإنشاء والحزم والتثبيت على Spark جديد متوافق. إن بنية تطوير الويب أدناه ليست أداة التثبيت ولا تبدأ تشغيل المنتج الكامل.

## التطوير

استخدم Node.js 24 وpnpm 11.1.3 (راجع الجذر `package.json`) وPython 3.10+ وإصدار Go المعلن في كل `go.mod` (وكيل العقدة حاليًا 1.26). على آلة البناء:

لا يحتوي التصدير المصدر عمدًا على سجل Git خاص. قبل تشغيل أدوات المصدر على تلك الشجرة المصدرة، قم بتهيئة المستودع الخاص بك وتنفيذ الشجرة التي تمت مراجعتها (`git init`, `git add .`, `git commit`). لا يحتاج استنساخ Git العام العادي إلى هذه الخطوة. استخدم هذا الالتزام الجديد كهوية البناء؛ لا تدعي أن الشجرة المعدلة المصدرة هي التزام التسليم القديم.

```sh
pnpm install --frozen-lockfile
pnpm --filter @teamaibox/web build
python3 tools/open_source_inventory.py --check
```

إن إنشاء الويب عبارة عن فحص تجميعي، وليس قبول المنتج. تستخدم خدمات وقت التشغيل ملفات Dockerfiles ضمن `deploy/`. يتطلب تنفيذ DGX Spark Linux ARM64 وبيئة NVIDIA/Docker الحالية. لا يعد فحص مصدر سطح المكتب بديلاً عن هذا الجهاز. لا تستخدم البرامج النصية المعملية التاريخية كمثبتات.

بالإضافة إلى ذلك، يتطلب مساعدو بناء مصنع Python استخدام PyYAML؛ راجع الاختبار المبدئي لتبعية المثبت. لا يلزم وجود قرص نظام تشغيل مثبت أو حساب مطور.

## استبعاد المدخلات المجمعة

يحذف المُصدِّر الملفات الثنائية، حتى عندما يبدو امتدادها غير ضار:

- إنشاء `services/node-agent` ومساعده `cmd/factory-worker-spec` من مصدر Go؛ جذر المستودع `node-agent` القابل للتنفيذ ليس إدخال مصدر.
- لا يتم شحن ملفات APK وملفات التوقيع الخاصة بنظام Android. يظل مصدرها وبياناتها ضمن `tools/fixtures/` متاحة للإصدارات التجريبية المحلية.
- يستخدم الإصدار الحالي لصب الأجهزة `deploy/appliance/wireless-casting-plugin.Dockerfile`. لا يحتاج إلى أرشيفات حزمة Alpine القديمة. إذا كنت تستخدم المكون الإضافي المستقل Dockerfile بدلاً من ذلك، فاحصل على الحزم المحددة المحددة في [بيان المجموع الاختباري الأولي](../../apps/wireless-casting-plugin/vendor/alpine/security-update-20261010.json) وتحقق من قيم SHA-256 الخاصة بها قبل الإنشاء. لا تقم أبدًا باستبدال حزمة عشوائية عندما تكون القطعة الأثرية المثبتة في المنبع غير متوفرة.
- تظل وحدة متصفح LiveKit وترخيصها في دليل المصدر العام للمكون الإضافي؛ لم يتم شحن أرشيف npm `.tgz` الزائد.

هذه هي استثناءات توزيع المصدر، وليست تغييرات على الجهاز قيد التشغيل.

## حزمة كاملة دون اتصال بالإنترنت

ابدأ بـ [مسار المصدر العام](../../install/PUBLIC-BUILD.ar.md). فهو يوفر الصور الأصلية العامة وتبعيات وقت التشغيل المبنية من المصدر؛ تثبيت المطور السابق غير مطلوب. وصفات الصور ذات الطبقات التاريخية ليست نقطة دخول التثبيت الجديد.

اتبع [install/README.md](../../install/README.ar.md) لإنشاءات صور التطبيقات وأدوات المضيف الضيف وحزم المضيف غير المتصلة بالإنترنت وجمع الأصول والتعبئة النهائية. لا يقوم الجهاز المستهدف بجلب التبعيات أو استبدال Docker/NVIDIA. قم بتعيين مدخلات البناء لالتزام المصدر الفعلي ومعرفات محتوى ARM64 OCI ومسارات الأصول النظيفة. لا يلزم وجود عنوان IP أو حساب أو شهادة أو وحدة تخزين لمضيف التطوير. يتم الحصول على أوزان النماذج وأصول الضيف/وقت التشغيل بشكل منفصل عن المصادر الأولية المحددة في [components.json](components.json) وأقفال المستودع. الحفاظ على تراخيصهم وإشعارات المصدر المطلوبة.

**توفر المصدر ليس تصريحًا لإعادة التوزيع الثنائي.** يشتمل العقد الحالي الكامل للحزمة غير المتصلة بالإنترنت على وقت تشغيل Google Android؛ دليل التثبيت الخاص به ليس إذنًا بتوزيع GMS. يتم الاحتفاظ بالحزمة الحالية دون تغيير، ولكن هذه الحزمة ليست تنزيلًا عامًا معتمدًا ما لم يتم الحصول على هذه الحقوق. سيكون الإصدار الثنائي العام لـ AOSP فقط عبارة عن تغيير تغليف منفصل النطاق، ولن يتم استبداله بصمت هنا. يتم توفير ملفات Windows/Linux ISO بواسطة كل مستخدم؛ لا يوجد ضيوف اختبار مثبتون أو حالات حساب تعتبر مدخلات بناء عامة.
