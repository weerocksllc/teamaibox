# Hak cipta dan cakupan asal

MIT diterapkan atas instruksi pemilik proyek ke kontribusi asli Team AI Box yang diatribusikan ke Weerocks LLC. Nama penulis Git adalah asal yang berguna, bukan bukti pekerjaan, penugasan, atau wewenang untuk melisensikan karya pihak ketiga. Sejarah lokal yang ditinjau memiliki 20 komitmen yang dapat dijangkau dan dua identitas penulis; rincian kontak penulis pribadi dan catatan pengembangan pribadi tidak disalin ke ekspor sumber. Tidak ada penugasan yang ditandatangani atau izin pemasok tambahan yang disimpulkan dari riwayat tersebut.

| Bahan | Perawatan lisensi | Bukti dan batasan |
| --- | --- | --- |
| Aplikasi/layanan/paket asli dan kode penginstal | MIT | instruksi pemilik proyek; LISENSI root dan metadata paket; header pihak ketiga yang ada menggantikan |
| Modifikasi UxPlay dan materi build yang menyertainya | GPL-3.0-only | Lisensi upstream yang ada, penerapan yang dipasangi pin, dan pemberitahuan sumber terkait di `deploy/legal/`; tidak dilisensikan ulang sebagai MIT |
| Modifikasi GStreamer WebRTC | MPL-2.0 | Lisensi upstream tingkat file dan catatan patch/build yang disematkan |
| Pustaka teks yang dibundel dan dependensi normal | Lisensi asli | Inventaris Lockfile, pemberitahuan yang disimpan, dan metadata registri versi tepat; metadata adalah indeks, bukan pengganti teks lisensi |
| Ketergantungan OCR PDF PyMuPDF | AGPL-3.0-or-later atau lisensi komersial | Versi 1.26.4 dan persyaratan lisensi ganda upstream; MIT tidak memberikan pengecualian komersial atau menyelesaikan kewajiban layanan gabungan |
| Bobot model, tamu Android, firmware, dan waktu proses GPU | Khusus komponen | Lihat `components.json`; hak sumber asli tidak secara otomatis mengizinkan redistribusi semua bobot atau kombinasi biner |
| Google Play/RUPS | Hak milik; tidak ada dalam artefak sumber publik | Kode integrasi berbeda dari gambar runtime kepemilikan; penggunaan tes pribadi yang ada bukan izin redistribusi |
| Pensiunan ViKey SDK dan manual/header vendor | Tidak termasuk; hak asli dilindungi undang-undang | Dihapus dari pohon sumber saat ini; dipertahankan secara pribadi, tidak diberi izin baru |
| Log pribadi, data akun, disk VM, sertifikat, dan riwayat Git lama | Tidak termasuk | Tidak ada dana redistribusi publik; ekspor sumber tidak mengandung riwayat pribadi |
| Situs web pemasaran, templat artikel, konten situs web, dan konfigurasi penerapan (`website/`) | Dikecualikan dari distribusi sumber produk publik | Dipelihara secara terpisah di repositori situs web pribadi; GitLab adalah arsip sejarah; berbeda dari UI alat di `apps/` |

Jangan menghapus pernyataan hak cipta hulu, mengatribusikan karya eksternal ke Weerocks, atau menganggap semua varian model yang memiliki nama serupa memiliki ketentuan yang sama. Seorang kontributor harus mempunyai kewenangan untuk mengirimkan karyanya; tidak ada CLA wajib baru yang diperkenalkan. Lihat [pemberitahuan pihak ketiga](../../THIRD_PARTY_NOTICES.id.md) untuk sumber komponen dan [batas rilis](RELEASING.id.md) untuk perbedaan sumber/biner.
