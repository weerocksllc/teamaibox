# สร้างต้นตอ

อาร์ติแฟกต์สาธารณะเป็นแหล่งที่มา ไม่ใช่อิมเมจของอุปกรณ์ออฟไลน์ที่สร้างไว้ล่วงหน้า บิลด์ต้นทางอาจดาวน์โหลดการขึ้นต่อกัน การติดตั้งโดยใช้แพ็คเกจเต็มรูปแบบที่เตรียมไว้ยังคงออฟไลน์อยู่ กระบวนการทั้งสองไม่ต้องการ ViKey SDK หรือคีย์ USB

สำหรับการติดตั้งอุปกรณ์โดยสมบูรณ์ ให้เริ่มต้นด้วยรูท [เริ่มต้นอย่างรวดเร็ว](../../README.th.md#install) และ [ตัวติดตั้งต้นทาง](../../install/SOURCE-INSTALL.th.md): `sudo bash install/from-source.sh` ดาวน์โหลด สร้าง จัดทำแพ็กเกจ และติดตั้งบน Spark ใหม่ที่เข้ากันได้ การสร้างเว็บเพื่อการพัฒนาด้านล่างไม่ใช่ตัวติดตั้งและไม่ได้เริ่มผลิตภัณฑ์ทั้งหมด

## การพัฒนา

ใช้ Node.js 24, pnpm 11.1.3 (ดูรูท `package.json`), Python 3.10+ และเวอร์ชัน Go ที่ประกาศในแต่ละ `go.mod` (node-agent ปัจจุบัน 1.26) บนเครื่องสร้าง:

การส่งออกต้นทางจงใจไม่มีประวัติ Git ส่วนตัว ก่อนที่จะเรียกใช้เครื่องมือต้นทางบนแผนผังที่ส่งออกนั้น ให้เริ่มต้นพื้นที่เก็บข้อมูลของคุณเองและยืนยันแผนผังที่ได้รับการตรวจสอบแล้ว (`git init`, `git add .`, `git commit`) โคลน Git สาธารณะปกติไม่จำเป็นต้องใช้ขั้นตอนนี้ ใช้การคอมมิตใหม่นั้นเป็นเอกลักษณ์ของบิลด์ อย่าอ้างว่าต้นไม้ที่ส่งออกและดัดแปลงนั้นเป็นคำสั่งส่งมอบเก่า

```sh
pnpm install --frozen-lockfile
pnpm --filter @teamaibox/web build
python3 tools/open_source_inventory.py --check
```

การสร้างเว็บเป็นการตรวจสอบการคอมไพล์ ไม่ใช่การยอมรับผลิตภัณฑ์ บริการรันไทม์ใช้ Dockerfiles ภายใต้ `deploy/` การดำเนินการ DGX Spark ต้องใช้ Linux ARM64 และสภาพแวดล้อม NVIDIA/Docker ที่มีอยู่ การชำระเงินแหล่งที่มาของเดสก์ท็อปไม่สามารถทดแทนฮาร์ดแวร์ดังกล่าวได้ อย่าใช้สคริปต์แล็บในอดีตเป็นตัวติดตั้ง

ตัวช่วยสร้างโรงงาน Python ต้องการ PyYAML เพิ่มเติม ดู preflight การพึ่งพาตัวติดตั้ง ไม่จำเป็นต้องมีดิสก์ระบบปฏิบัติการหรือบัญชีนักพัฒนาที่ติดตั้งไว้

## ไม่รวมอินพุตที่คอมไพล์แล้ว

ผู้ส่งออกละเว้นไฟล์ไบนารี แม้ว่าส่วนขยายจะดูไม่เป็นอันตรายก็ตาม:

- สร้าง `services/node-agent` และตัวช่วย `cmd/factory-worker-spec` จากแหล่งที่มา Go ไฟล์ปฏิบัติการ repository-root `node-agent` ไม่ใช่อินพุตต้นทาง
- APK การติดตั้ง Android และไฟล์การลงนามจะไม่ถูกจัดส่ง แหล่งที่มาและรายการภายใต้ `tools/fixtures/` ยังคงพร้อมใช้งานสำหรับรุ่นทดสอบในเครื่อง
- โครงสร้างการหล่ออุปกรณ์ในปัจจุบันใช้ `deploy/appliance/wireless-casting-plugin.Dockerfile` ไม่จำเป็นต้องมีไฟล์เก็บถาวรแพ็คเกจ Alpine เก่า หากคุณใช้ปลั๊กอิน Dockerfile แบบสแตนด์อโลนแทน ให้รับแพ็กเกจที่แน่นอนที่ระบุใน [รายการตรวจสอบอัปสตรีม](../../apps/wireless-casting-plugin/vendor/alpine/security-update-20261010.json) และตรวจสอบค่า SHA-256 ก่อนสร้าง อย่าเปลี่ยนแพ็คเกจที่กำหนดเองเมื่ออาร์ติแฟกต์อัปสตรีมที่ปักหมุดไว้ไม่พร้อมใช้งาน
- โมดูลเบราว์เซอร์ LiveKit และใบอนุญาตยังคงอยู่ในไดเรกทอรีต้นทางสาธารณะของปลั๊กอิน ไฟล์เก็บถาวร npm `.tgz` ที่ซ้ำซ้อนไม่ได้ถูกจัดส่ง

สิ่งเหล่านี้เป็นการยกเว้นการกระจายแหล่งที่มา ไม่ใช่การเปลี่ยนแปลงในอุปกรณ์ที่ทำงานอยู่

## แพ็คเกจออฟไลน์ที่สมบูรณ์

เริ่มต้นด้วย [ไปป์ไลน์แหล่งที่มาสาธารณะ](../../install/PUBLIC-BUILD.th.md) โดยจัดเตรียมอิมเมจพาเรนต์สาธารณะและการขึ้นต่อกันของรันไทม์ที่สร้างจากแหล่งที่มา ไม่จำเป็นต้องติดตั้งผู้พัฒนาก่อนหน้านี้ สูตรรูปภาพแบบเลเยอร์ในอดีตไม่ใช่จุดเริ่มต้นการติดตั้งใหม่

ปฏิบัติตาม [install/README.md](../../install/README.th.md) สำหรับการสร้างอิมเมจแอปพลิเคชัน เครื่องมือโฮสต์ของแขก แพ็คเกจโฮสต์ออฟไลน์ การรวบรวมสินทรัพย์ และการบรรจุขั้นสุดท้าย อุปกรณ์เป้าหมายไม่ดึงข้อมูลการขึ้นต่อกันหรือแทนที่ Docker/NVIDIA ตั้งค่าอินพุตบิวด์ให้กับการคอมมิตแหล่งที่มาจริงของคุณ, ID เนื้อหา ARM64 OCI และเส้นทางสินทรัพย์ที่สะอาด ไม่จำเป็นต้องมี IP โฮสต์การพัฒนา บัญชี ใบรับรอง หรือวอลุ่ม น้ำหนักโมเดลและเนื้อหาเกสต์/รันไทม์จะได้รับแยกต่างหากจากต้นทางอัปสตรีมที่ระบุใน [components.json](components.json) และการล็อกที่เก็บข้อมูล เก็บรักษาใบอนุญาตและประกาศแหล่งที่มาที่จำเป็น

**ความพร้อมใช้งานของแหล่งที่มาไม่ใช่การกวาดล้างการแจกจ่ายซ้ำแบบไบนารี** สัญญาแพ็คเกจออฟไลน์ที่สมบูรณ์ในปัจจุบันประกอบด้วยรันไทม์ของ Google Android; หลักฐานการติดตั้งส่วนตัวไม่ได้รับอนุญาตให้เผยแพร่ GMS ตัวทำแพ็คเกจที่มีอยู่จะยังคงไม่เปลี่ยนแปลง แต่แพ็คเกจดังกล่าวไม่ถือเป็นการดาวน์โหลดสาธารณะที่ได้รับอนุมัติ เว้นแต่จะได้รับสิทธิ์เหล่านั้น ไบนารี่สาธารณะรุ่น AOSP เท่านั้นจะเป็นการเปลี่ยนแปลงบรรจุภัณฑ์ที่มีขอบเขตแยกกัน โดยไม่มีการแทนที่ในที่นี้ ไฟล์ ISO ของ Windows/Linux จัดทำโดยผู้ใช้แต่ละคน ไม่มีแขกทดสอบหรือสถานะบัญชีที่ติดตั้งไว้เป็นอินพุตบิลด์สาธารณะ
