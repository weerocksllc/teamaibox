# ขอบเขตความเป็นส่วนตัวของแหล่งข้อมูลสาธารณะ

พื้นที่เก็บข้อมูลผลิตภัณฑ์สาธารณะเป็นสแน็ปช็อตแหล่งที่มาใหม่ ไม่ใช่ภาพสะท้อนของประวัติการพัฒนาส่วนตัว เว็บไซต์การตลาดมีพื้นที่เก็บข้อมูลส่วนตัวของตัวเองและไม่ได้รวมอยู่ที่นี่

## วัสดุที่ถูกลบออก

- แก้ไขชื่อบัญชีทดสอบการใช้งานและรหัสผ่าน และรายการบัญชีส่วนบุคคล
- Wrapper และสคริปต์การใช้งาน/การกู้คืนในอุปกรณ์เดียวที่บันทึกข้อมูลประจำตัวของอุปกรณ์ในอดีตหรือยืนยันผลลัพธ์จากหลักฐานส่วนตัว
- ที่อยู่โฮสต์จริง โฮมไดเร็กทอรี ข้อมูลประจำตัวคอนเทนเนอร์/อุปกรณ์ และภาพรวมการบำรุงรักษาในอดีต การทดสอบที่คงไว้ใช้ฟิกซ์เจอร์สังเคราะห์อย่างชัดเจน เครื่องมือในการปฏิบัติงานที่ได้รับการบำรุงรักษาจำเป็นต้องมีอินพุตเป้าหมายที่ชัดเจน
- ดิสก์ของผู้เยี่ยมชม สถานะการเข้าสู่ระบบ Android เซสชันเบราว์เซอร์ แพ็คเกจการติดตั้ง น้ำหนักโมเดล และหลักฐานส่วนตัวอยู่นอกการเผยแพร่แหล่งที่มาสาธารณะ

ที่เก็บถาวรส่วนตัวและแท็กการจัดส่งดั้งเดิมยังคงไม่เปลี่ยนแปลง ไม่มีสิ่งใดในการล้างข้อมูลแหล่งที่มานี้เปลี่ยนแปลงบัญชีอุปกรณ์ ข้อมูลแขก บริการที่ทำงานอยู่ หรือการปรับใช้เว็บไซต์ ค่าเริ่มต้นจากโรงงาน `admin / admin` ถูกเก็บไว้โดยเจตนา ไม่ใช่ข้อมูลประจำตัวส่วนตัว ผู้ดูแลระบบจะต้องเปลี่ยนก่อนที่จะเปิดเผย

## ตรวจสอบและยืนยัน

ตรวจสอบทั้งแผนผังงานและคอมมิต/แท็กทั้งหมดที่เข้าถึงได้ในพื้นที่เก็บข้อมูลที่กำลังเผยแพร่ ใช้ Gitleaks บวก `tools/open_source_sensitive.py`; เพียงอย่างเดียวก็พิสูจน์ได้ว่าไม่มีรหัสผ่านเอนโทรปีต่ำหรือข้อมูลเมตาส่วนบุคคล เปรียบเทียบค่าส่วนตัวเก่าที่ยืนยันแล้วโดยใช้รายการปฏิเสธภายนอกส่วนตัว โดยไม่มีการทดสอบแบบผูกมัด ตรวจสอบผลการวิจัยที่เหลือทีละรายการ รวมถึงไฟล์ทดสอบ

การตรวจสอบการล้างข้อมูลคือการตรวจสอบนโยบายแหล่งที่มา การถดถอยสังเคราะห์ การกำหนดค่า และไวยากรณ์ พวกเขาไม่ได้เข้าสู่ระบบโดยใช้ข้อมูลประจำตัวที่ค้นพบ ติดตั้งกล่องใหม่ หรือยอมรับผลิตภัณฑ์ซ้ำ การแก้ไขแพ็กเกจ API ก่อนหน้านี้ (รวมถึงแหล่งที่มาของ UI ที่ใช้ร่วมกันและการตรวจสอบจุดเข้าใช้งานที่นำเข้าเท่านั้น) จะยังคงอยู่ในแหล่งที่มา

โคลนใหม่จะต้องไม่นำเข้าคอมมิต การอ้างอิง หรือแท็กที่เลิกใช้แล้ว การลบพื้นที่เก็บข้อมูลจะไม่จำสำเนาที่ผู้อื่นดาวน์โหลดไปแล้ว ไม่มีการสแกนใดที่สามารถพิสูจน์ได้ว่าไม่เคยคัดลอกข้อมูลประจำตัวที่ไม่รู้จัก ข้อมูลประจำตัวที่ใช้จริงจะต้องถูกหมุนเวียนโดยผู้ปฏิบัติงาน การล้างข้อมูลนี้ไม่ได้อ้างว่าได้หมุนเวียนแล้ว
