# ขอบเขตลิขสิทธิ์และแหล่งที่มา

MIT นำไปใช้กับคำสั่งของเจ้าของโครงการกับการสนับสนุน Team AI Box ดั้งเดิมที่มาจาก Weerocks LLC ชื่อผู้เขียน Git เป็นที่มาที่เป็นประโยชน์ ไม่ใช่หลักฐานการจ้างงาน การมอบหมาย หรืออำนาจในการอนุญาตงานของบุคคลที่สาม ประวัติศาสตร์ท้องถิ่นที่ได้รับการตรวจสอบแล้วมีความมุ่งมั่นที่สามารถเข้าถึงได้ 20 รายการและตัวตนของผู้เขียนสองคน รายละเอียดการติดต่อผู้เขียนส่วนบุคคลและบันทึกการพัฒนาส่วนตัวจะไม่ถูกคัดลอกไปยังการส่งออกต้นทาง ไม่มีการมอบหมายการลงนามหรือการอนุญาตเพิ่มเติมจากซัพพลายเออร์จากประวัติดังกล่าว
