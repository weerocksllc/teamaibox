# Объем авторских прав и происхождения

MIT применяется по указанию владельца проекта к исходным вкладам Team AI Box, приписываемым Weerocks LLC. Имена авторов Git являются полезным источником происхождения, а не доказательством трудоустройства, назначения или полномочий лицензировать работу третьих лиц. Просматриваемая локальная история имеет 20 доступных коммитов и две личности автора; личные контактные данные автора и записи частных разработок не копируются в исходный экспорт. Из этой истории не следует никакого подписанного задания или дополнительного разрешения поставщика.
