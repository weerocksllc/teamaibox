# 저작권 및 출처 범위

MIT는 Weerocks LLC에 귀속된 원본 Team AI Box 기여에 대한 프로젝트 소유자의 지시에 적용됩니다. Git 작성자 이름은 유용한 출처이지 고용, 할당 또는 제3자 작업 라이선스에 대한 권한을 증명하는 것이 아닙니다. 검토된 로컬 기록에는 도달 가능한 커밋 20개와 ​​작성자 ID 2개가 있습니다. 개인 작성자 연락처 세부 정보 및 개인 개발 기록은 소스 내보내기에 복사되지 않습니다. 해당 기록에서는 서명된 할당이나 추가 공급업체 허가가 유추되지 않습니다.
