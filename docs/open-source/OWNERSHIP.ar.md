# نطاق حقوق النشر والمصدر

يتم تطبيق MIT بناءً على تعليمات مالك المشروع على مساهمات Team AI Box الأصلية المنسوبة إلى Weerocks LLC. تُعد أسماء مؤلفي Git مصدرًا مفيدًا، وليست دليلاً على التوظيف أو التعيين أو السلطة لترخيص عمل جهة خارجية. يحتوي التاريخ المحلي الذي تمت مراجعته على 20 التزامًا يمكن الوصول إليه وهويتين للمؤلف؛ لا يتم نسخ تفاصيل الاتصال الشخصية للمؤلف وسجلات التطوير الخاصة إلى التصدير المصدر. لا يتم استنتاج أي مهمة موقعة أو إذن إضافي للمورد من هذا التاريخ.
