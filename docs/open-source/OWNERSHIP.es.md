# Copyright y alcance de procedencia

MIT se aplica según las instrucciones del propietario del proyecto a las contribuciones originales Team AI Box atribuidas a Weerocks LLC. Los nombres de los autores de Git son una procedencia útil, no una prueba de empleo, asignación o autoridad para licenciar trabajos de terceros. La historia local revisada tiene 20 confirmaciones accesibles y dos identidades de autor; Los datos de contacto personales del autor y los registros de desarrollo privados no se copian en la exportación de origen. De ese historial no se infiere ninguna cesión firmada ni permiso adicional de proveedor.
