# 使用虚拟电脑

## 当前开放范围

工作台的“虚拟电脑”和“虚拟手机”是两个独立入口。当前交付支持已验证配置的 Windows 11 ARM64；成员浏览器桌面、声音、数据保持和故障恢复已有通过记录，不再列作待测。Windows 10 ARM64 **当前不提供**：没有取得可核实且可使用的对应介质和适用权利，不能继承 Windows 11 的结果。

当前版本会为你创建独立磁盘并启动 Windows 安装程序，**不是点击创建后就已经安装好 Windows**。交付的是虚拟电脑管理与浏览器使用能力；Windows 由客户使用适用授权的介质安装。现有测试档案不允许镜像再分发，不把带测试账户的磁盘作为客户预装模板。需要预装交付时另行确认对应权利，不通过重新测试来替代。

## 创建与安装

> 新增的 Windows/Linux 用户 ISO 安装流程正在做首次实机验收，两个新硬件选项已为这次临时电脑验收开放。以下操作说明不表示完整安装验收已经通过；进度见 [本次安装功能记录](validation/computer-installation-acceptance-20261024.md)。现有电脑和已交付 Windows 功能不因此重装。

### 自备 ISO 的新流程

1. 打开“虚拟电脑 → 创建电脑”，填写名称，选择已开放的 Windows 或 Linux 配置、CPU、内存和磁盘。
2. 点击“选择安装盘”：可“上传 ISO”，也可“从网盘选择”。需要 ARM64 的可引导安装盘；x64 安装盘不能在当前加速配置中启动。无法确定架构的自定义盘会提示，需明确确认才能尝试。
3. 上传显示进度，可以暂停、重新选择同一文件续传，或取消。网盘选择会按当时有权读取的文件版本生成私有安装副本，额外占用空间；之后源文件修改或删除不会偷偷更换安装盘。
4. 选好就绪的安装盘后点击“创建并安装”。系统保存一台独立空电脑，挂载光盘并请求开机；打开它的虚拟显示器，按 Windows/Linux 自己的安装界面操作。平台不代替你接受许可、设置系统账户或激活。
5. 也可选择“先创建空电脑”，稍后在该电脑的“安装系统与光驱”中选盘。开机失败会保留这台电脑，修正原因后在原电脑上继续，不用再建一台。

### 光驱、重启和安装完成

- 电脑卡片和虚拟显示器都有“安装系统与光驱”入口。挂载、更换、弹出只操作安装光盘，不操作系统盘；Windows 的驱动光盘独立保留。
- “下次从光盘启动”只设置下一次开机的意图，不会自动重启正在使用的系统。请先保存工作，在虚拟机中正常关机，再开机。不要通过强制断电来开始安装。
- 部分 Windows 安装盘会短暂显示“Press any key to boot from CD or DVD”，需要及时在虚拟显示器内按键。若错过提示、空白电脑回到固件菜单，可在 Boot Manager 中重新选择安装光驱后按键，无需删除或重建电脑。
- Windows 首次设置若提示找不到网络，可点击“安装驱动程序”，在已挂载的 VirtIO 驱动光盘中选择 `NetKVM → w11 → ARM64`。这是虚拟网卡驱动，光盘盘符可能不同；不要选择 `amd64` 目录，也不需要关闭驱动签名检查。
- 安装器自行重启时，光盘仍保持挂载，正常优先从已经写好的系统盘启动。光盘启动意图消费后不会因为网页刷新而再次安排安装启动。
- 如果系统正在锁定光盘，弹出会被拒绝。请先在虚拟机内释放光盘，再重试；平台不会强制弹出。
- 关闭网页不关机、不取消已经开始的安装。重新打开显示器继续同一台电脑、同一份磁盘。
- 安装完成后可以弹出安装盘，并点击“我已完成安装”。这只是你的确认，不代表平台已检查系统内所有驱动或软件。
- 删除安装副本不会删除网盘源文件；仍在挂载或用于待执行操作的副本不能删除。电脑主人才能管理介质，显示器的观看/控制邀请不会授予这项权限。
- 旧电脑未启用新光驱控制时，正常关机后可显式“启用光驱管理”。此操作保留原磁盘、固件变量和 TPM，不会把旧电脑标记为空白或重新分区。

### 既有 Windows 配置

1. 登录主盒工作台，打开“专业工具 → 虚拟电脑”。
2. 点击“创建电脑”，填写名称、选择系统及所需 CPU、内存、磁盘容量。
3. 创建完成后点击“打开显示器”，在需要时点击“开机”。按画面中的 Windows 安装程序完成安装、许可确认和账户设置。
4. 安装完成后继续使用同一个虚拟显示器，不需要先配置 Windows 远程桌面。

“打开显示器”就是查看这台虚拟电脑本身的屏幕，可以看到固件引导、Windows 登录、桌面和重启过程，不额外要求远程桌面用户名、密码。画面中 Windows 自身的登录要求仍然保留。需要声音时点击“开启声音”；浏览器禁止自动播放时需要这次点击。

“更多 → 远程桌面”是可选的另一种连接方式，需要 Windows 版本支持并启用远程桌面，且网络、账户登录正常。它与虚拟显示器连接同一台电脑，不会生成另一份磁盘。

新电脑需要自己的 Windows 账户。不要把主盒平台账户和 Windows 账户混为一谈。Windows 的激活状态、许可证和远程使用条件需要按所选版本单独确认；平台创建成功不代表 Windows 已激活。

### 安装后的时间设置

第一次装完 Windows 要核对日期和时间。当前虚拟硬件使用 UTC 时钟；Windows 应按 UTC 读取硬件时钟，再按你选择的时区显示，否则中国时区可能慢 8 小时。不要通过修改盒子的时间或关闭证书检查来处理。

开发维护人员可在这台 Windows 的管理员 PowerShell 中运行仓库内的 `tools/fixtures/windows-utc-clock.ps1`，也可以执行下面两条配置后重启 Windows。它们不改账户、密码或显示时区：

```powershell
New-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\TimeZoneInformation' -Name RealTimeIsUniversal -PropertyType DWord -Value 1 -Force
Set-Service W32Time -StartupType Automatic; Start-Service W32Time
```

再用 `w32tm /resync /rediscover` 检查原有时间服务器。如果报告没有时间数据，表示网络校时还没有通过，不应把“服务已启动”当作同步成功。此配置目前是安装后准备步骤，尚未自动注入所有新电脑。

本次测试还发现，默认 `time.windows.com,0x9` 使用 16384 秒固定轮询，开机后曾长时间没有自动同步。独立、未加入域且未受时间组策略管理的测试电脑，已保留同一服务器，改用 Windows 内置动态轮询 `time.windows.com,0x8`；正常重启后约 28 秒自动同步成功。维护脚本增加可选 `-UseAdaptivePolling`，遇到自定义服务器、域或组策略会拒绝覆盖。不要把这个选项用于替换公司的域校时策略。没有增加计划任务或常驻代理；这是一次已测开机结果，不是所有网络条件下的保证。

## 关闭页面、关机和删除的区别

- **关闭或离开网页**：只断开当前观看连接，不关闭 Windows，不释放正在使用的运行资源。
- **关机**：请求 Windows 正常关机；系统盘、应用、文件和账户继续保存。系统仍在关机时，不应把它当作已经释放资源。
- **删除**：只对已经停止的电脑执行，并需要确认。会删除该电脑的数据；普通的关机或页面更新不会替你执行删除。
- **刷新或重新连接**：重新接入原电脑，不重装系统、不更换账户，也不应创建重复磁盘。

在 Windows 开始菜单里关机也会自动更新网页状态，确认退出后释放运行内存，磁盘继续保留。本机管理服务短暂不可用不会被当作已关机，也不会直接释放仍可能被 Windows 使用的资源。意外停止时，网页会说明原磁盘仍在，可以重新开机；Windows 可能自行检查磁盘。

## 资源不足时

创建和启动会检查本机的实际可用 CPU、内存及存储，也计入电脑运行开销和已承诺但尚未写满的磁盘空间。不会为了启动电脑而停掉常驻办公模型，不应靠额外 swap 超额分配内存。

手机和电脑的共享存储不再设定 256 GiB 或 384 GiB 的总容量上限。可创建容量以本机硬盘的实际可用空间为准，同时扣除已有设备尚未写满的已承诺空间及必要运行余量。扩展共享存储不会扩大或清空已有电脑的虚拟硬盘。

如果不能启动，先看页面给出的具体原因。保存着的磁盘和正在运行的内存不是同一项：关机可以释放运行资源，但不会释放仍然保存的系统盘。不要为“重试开机”删除已有电脑。

## 连接问题

- 刚创建的电脑尚未安装 Windows：打开显示器完成安装，不必等待远程桌面可用。
- 页面刷新后需重新连接：连接原电脑即可，不要重新创建。
- 自己在另一页面打开了显示器：两个页面都可以观看，不会互相拦截；第二页默认仅观看，需要操作时点击“接管控制”。可选的远程桌面仍保留原有单连接规则。
- 显示器已连接但屏幕黑着：Windows 可能正在锁屏或关闭显示；在有控制权的页面唤醒 Windows。不要因此重装系统。
- 只有“更多 → 远程桌面”连不上：用虚拟显示器检查 Windows 的网卡、远程桌面设置及账户，不要重建电脑。
- Windows 正在重启：等待系统回到可连接状态；短暂没有图像不等于系统盘丢失。
- 设备或本机管理服务暂不可用：不要重置 Windows 账户或删除磁盘。先恢复盒子连接，再核对原电脑的真实状态。

管理员的资源管理权限不自动授予查看其他用户桌面或文件的权限。

## 多人观看与控制

在虚拟显示器工具栏点击 **“参与者与邀请”**。各页面看到的是同一台电脑、同一个 Windows 会话，不是分别创建桌面或复制磁盘。

1. **邀请别人**：主人搜索成员姓名或账号，选择“仅观看”或“允许控制”，点击“发送邀请”。对方登录盒子后，从 **“虚拟电脑 → 邀请我的电脑”** 中打开；不需要查找另一处通知。
2. **默认一人控制**：首个有控制权限的页面获得控制权，其余页面可观看。当前控制者或主人可以在参与者列表点击“交给此页面”。没有控制者时，有控制权限的成员可点击“接管控制”。
3. **共同控制**：主人勾选“允许共同控制”后，获准控制的成员和主人页面可以同时操作；仅观看的成员仍不能操作。大家共用鼠标和键盘，操作可能互相影响。
4. **主人收回**：点击“收回全部控制权”，立即结束共同控制并将操作权收回当前主人页面。其他人继续观看；这不删除他们的邀请。
5. **撤销邀请**：在“已邀请成员”中撤销，会立即断开该成员所有观看页面；以后也无法重新连接，除非主人重新邀请。改为“仅观看”会立即停止其输入权限。

邀请保存在盒子中，关闭页面不会清除邀请。当前页面控制权是临时状态：离开后释放；服务重启后恢复默认的一人控制模式。邀请只允许观看/控制，不授予开关机、删除电脑、磁盘管理或可选远程桌面的权限。参与者退出和交接会释放其按住的键及鼠标按钮。

## 管理员设置

在左侧“管理 → 虚拟电脑”中，可以暂停或恢复新建和开机、设置每台电脑的 CPU/内存/磁盘上限，以及每个用户可保存和同时运行的数量。留空表示不另设数量上限，仍按设备实际资源分配；0 表示不允许新增相应资源。

暂停、调低额度或更新网页不会关闭正在使用的电脑，也不会删除已有磁盘。用户额度可通过姓名或账号搜索后单独调整；页面还显示可用系统、设备状态、运行数量及实际运行状态。设置保存在主盒数据库，服务重启后保留。

管理员可以单独暂停某个 Windows 系统的新建，不影响已创建的电脑。导入系统描述文件时，新版本先保持未开放；主盒确认本机执行服务已安装对应的系统介质和运行程序后，才允许开放新建。导入描述文件本身不会下载 Windows，也不会替换已有电脑的系统盘。相同版本可以重复导入；更改系统内容须使用新的版本编号。激活、远程使用和分发条件由管理员根据所用介质填写，导入或开放操作不会自动获得许可证。

## 数据与支持边界

电脑磁盘、固件变量及虚拟 TPM 状态需要一起保留。页面更新不应替换这些内容。独立加密磁盘不等于已有备份；重要文件仍需要单独备份。

当前没有承诺显卡直通、CUDA、游戏性能或自动迁移磁盘。Windows 内部主题由 Windows 自己设置，主盒网页的深浅色主题不会强制改变它。
