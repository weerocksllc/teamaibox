# 本机维护操作

## 维护范围

页面更新、容器服务更新与宿主驱动/内核更新是不同范围；不要为页面改动触发整机维护。部署配置位于 `deploy/appliance`，本机身份由 `PLATFORM_APPLIANCE_NODE_ID` 固定。

## 准备

在管理界面核对唯一设备身份、当前版本和待修改组件。保存当前配置、原镜像及精确回退方式，说明受影响服务和预计停机。不得顺带格式化数据盘、变更解锁方式或重装用户手机和电脑。

## 执行

对本机执行已批准维护。只暂停确有必要的工作，不改用户路由/VPN，不依赖别的设备接管。每步检查实际结果；失败后不要继续扩大修改范围。

## 失败与回退

失败时按记录回退；不能安全回退时保留现场并说明具体恢复操作。`manual_recovery_required` 表示恢复未完成，不是可以忽略的提示。不要通过重新初始化设备或删除原盘掩盖故障。

## 完成检查

验证存储解锁、核心 API/身份、办公服务和本次受影响的 Android/Windows/投屏入口。记录修改前后的版本、身份和结果，不记录密码或用户内容；未受影响且仍有效的测试不重复执行。
