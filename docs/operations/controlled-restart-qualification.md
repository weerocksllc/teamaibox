# 单盒恢复检查

恢复验证只覆盖当前设备和受本次改动影响的组件，不重复运行已完成且未变化的发布长测。

1. 记录本机身份、原容器、客体磁盘、正在运行的任务与存储状态。
2. 先验证受影响服务进程重启：原数据、任务幂等性、页面恢复、Android/Windows 原运行身份必须保持。
3. 需要整机重启时在已授权维护窗口执行。开机检查存储解锁、本地 Agent、基础服务、办公模型与用户页面，不自动重建客体。
4. 验证至少一部 Android、一台 Windows、常驻办公与浏览器投屏的统一容量。未知状态不能当成已停机释放资源。
5. 保存本次成功或失败结果，清理仅本次创建的测试资源；不能拼接失败与成功运行。

可复用的旧证据只证明其原始范围。此前测试编排保留在 [历史记录](../validation/controlled-restart-qualification-before-single-appliance-20261016.md)，不是当前必跑命令表。当前发布范围以 OpenSpec 单盒任务为准。
