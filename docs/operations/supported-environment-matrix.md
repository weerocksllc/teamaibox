# 单盒支持环境与发布范围

Team AI Box 只交付单台 DGX Spark 设备。所有必备功能由该设备完成；外部 OpenAI 兼容 API 是独立可选集成，不参与证明出厂能力。

## 当前环境合同

| 部分 | 要求 | 验证方式 |
| --- | --- | --- |
| 设备 | ARM64 DGX Spark / GB10，统一内存 | 读取本机真实 CPU、内存、GPU 与驱动信息，不虚构独立显存 |
| 系统 | 已验证的 DGX OS、内核、NVIDIA 驱动与容器运行时组合 | 更新后只复测受影响能力，不能把旧环境通过自动移植到新版本 |
| 本机身份 | `PLATFORM_APPLIANCE_NODE_ID` 为精确持久 UUID | 所有 Worker、手机、Windows、存储与摄像头绑定同一本机 |
| 管理入口 | `/admin/device`；`GET /api/v1/admin/appliance` | 显示唯一设备状态和实际容量，无设备列表、添加或远程安装入口 |
| 数据 | 已授权的本地 LUKS2 数据池、对象加密 | 验证当前池、钥匙和原数据；安装不会隐式格式化任何磁盘 |
| 网络 | 浏览器 HTTPS/WSS 与加密媒体；本地控制通信不出设备 | 不修改用户 VPN、宿主路由或要求专用互联 |
| 本机办公 | 六项已部署常驻办公能力 | 实际请求、运行状态与失败原因，不以进程存在代替功能 |
| 虚拟手机 | 至少一部 Android；标准 Android / Android + Google Play | 本机 KVM、原盘恢复、浏览器画面/声音/输入；Google 兼容性单独披露 |
| 虚拟电脑 | 至少一台 Windows 11 ARM64 | 本机 KVM、持久磁盘与真实浏览器桌面；新建后需安装系统，Windows 10 ARM64 当前不提供 |
| 投屏 | Apple 设备到浏览器，可邀请有权用户 | 浏览器接收、断开反馈、恢复和资源占用；不提供 HDMI 输出 |

## 容量与兼容性

- 六项常驻办公能力、至少一部 Android、一台 Windows 和一场浏览器投屏需要在同一设备组合验证。
- CPU、内存、编解码与网络由操作系统共享，不按配置上限提前扣减；存储显示实际使用与物理可用空间，真实故障明确报告。
- 高内存独占绘图仍遵守已确认的 80 GiB 硬上限、32 GiB 核心保留、16 GiB 余量及排空后 96 GiB admission；不能挤掉出厂承诺的常驻业务。
- 未知或过期测量显示未知，不能当作零负载或可用容量。
- 新规格是可配置并需真实容量支持的规格，不把某次实验默认值写成无依据的永久硬上限。
- Google Play 可用不等于 Google 设备认证；Windows 镜像可启动不等于激活或分发权利已取得。
- ARM64、软件绘图、具体模型/格式、浏览器能力的限制按实际组件披露；不声称所有 Android/Windows 应用兼容。
