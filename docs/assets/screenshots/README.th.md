# ภาพหน้าจอผลิตภัณฑ์สาธารณะ

นี่คือการจับภาพเวิร์กเบนช์จริงของ Team AI Box ภาพแสงหนึ่งภาพและภาพมืดหนึ่งภาพสำหรับแต่ละสถานที่ของ UI ทั้ง 17 แห่ง เป็นสินทรัพย์เอกสารประกอบผลิตภัณฑ์ ไม่ใช่แหล่งที่มา เทมเพลต หรือเอาท์พุตของเว็บไซต์การตลาดส่วนตัว

## กฎการจับ

- ใช้ภาษาและการควบคุมธีมของผลิตภัณฑ์จริง อย่าแปลป้ายกำกับเป็นภาพหน้าจอภาษาอังกฤษหรือสร้างผลลัพธ์ที่ประสบความสำเร็จ
- ใช้บัญชีสาธิตและตรวจสอบทุกภาพเพื่อดูข้อความส่วนตัว ชื่อไฟล์ ข้อมูลประจำตัว PIN ของผู้รับ ที่อยู่เครือข่าย และ Chrome ของเบราว์เซอร์ ห้ามเผยแพร่ดิสก์ของผู้เยี่ยมชมที่ลงชื่อเข้าใช้หรือส่งออกเซสชัน/คุกกี้ด้วยรูปภาพ
- การจับภาพเวิร์กเบนช์ปัจจุบันแสดงเฉพาะสถานะงานสาธิตทั่วไปและบัญชีผู้ดูแลระบบทั่วไป พวกเขาไม่ได้เปิดเผยเพย์โหลดงาน
- คงการตั้งค่าผลิตภัณฑ์ไว้เหมือนเดิมหลังจากการจับภาพ อย่าลบข้อมูลผู้ใช้หรือเรียกใช้ปริมาณงานทางธุรกิจอีกครั้งเพื่อรับภาพหน้าจอ
- `workbench-light.jpg` and `workbench-dark.jpg` เป็นต้นฉบับ ส่วนใหญ่ใช้การจับภาพแบบเต็มหน้า ภาษาอาหรับใช้วิวพอร์ตจริงเนื่องจากการจับภาพ RTL แบบเต็มหน้าของเบราว์เซอร์แทนที่หน้า ไม่มีการเปลี่ยนแปลงป้ายกำกับหรือผลลัพธ์
- คำสถานะงานสดบางคำยังคงเป็นภาษาอังกฤษในมุมมองที่แปลเป็นอย่างอื่น รูปภาพเหล่านี้จงใจรักษา UI ที่จัดส่งไว้แทนที่จะรีทัช ระบบปฏิบัติการของแขก การตอบกลับของโมเดล และชื่อที่ผู้ใช้กำหนดมีการตั้งค่าภาษาที่แยกจากกัน และไม่ได้รับการแปลโดยตัวเลือก UI

ตัวเรนเดอร์ README ต้องการทั้งรูปภาพสำหรับทุกภาษาของผลิตภัณฑ์และล้มเหลว แทนที่จะถอยกลับไปเป็นภาพหน้าจอภาษาอังกฤษ เมื่อรีเฟรช UI ให้แทนที่ทั้งสองธีมและสร้างรายการรูปภาพใหม่ด้วย `node tools/screenshot-manifest.mjs` เก็บตัวระบุเครือข่าย/อุปกรณ์และบันทึกการบันทึกในเครื่องออกจากไดเร็กทอรีสาธารณะนี้
