# Публичные скриншоты продукта

Это настоящие снимки рабочей среды Team AI Box, одно светлое и одно темное изображение для каждой из 17 локалей пользовательского интерфейса. Это активы документации по продукту, а не исходный код, шаблоны или выходные данные частного маркетингового веб-сайта.

## Правила захвата

- Используйте актуальный язык продукта и элементы управления темами; не переводите надписи на английский скриншот и не придумывайте успешный результат.
- Используйте демонстрационную учетную запись и проверяйте каждое изображение на наличие личных сообщений, имен файлов, учетных данных, PIN-кодов получателя, сетевых адресов и Chrome браузера. Никогда не публикуйте гостевой диск, для которого выполнен вход в систему, а также экспортируйте сеанс или файл cookie с изображениями.
- Текущие снимки рабочей среды показывают только общее состояние демонстрационной задачи и общую учетную запись администратора. Они не раскрывают полезные данные задач.
- Сохраняйте настройки продукта такими, какими они были после захвата. Не удаляйте пользовательские данные и не запускайте повторно рабочие нагрузки для получения снимка экрана.
- `workbench-light.jpg` and `workbench-dark.jpg` — оригиналы. Большинство из них используют полностраничный захват. В арабском языке используется фактическая область просмотра, поскольку полностраничный захват RTL браузера сместил страницу; никакие метки или результаты не были изменены.
- Некоторые текущие слова состояния задач по-прежнему написаны на английском языке в локализованных представлениях. Эти изображения намеренно сохраняют поставляемый пользовательский интерфейс, а не ретушируют его. Гостевые операционные системы, ответы моделей и определяемые пользователем имена имеют отдельные языковые настройки и не переводятся селектором пользовательского интерфейса.

Средство рендеринга README требует обоих изображений для каждого языкового стандарта продукта и дает сбой вместо того, чтобы автоматически вернуться к английскому снимку экрана. При обновлении пользовательского интерфейса замените обе темы и заново создайте манифест изображения с помощью `node tools/screenshot-manifest.mjs`. Храните идентификаторы сети/устройства и локальные журналы захвата в этом общедоступном каталоге.
