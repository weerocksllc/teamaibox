# 公開されている製品のスクリーンショット

これらは実際の Team AI Box ワークベンチ キャプチャであり、17 の UI ロケールごとに 1 つの明るい画像と 1 つの暗い画像です。これらは製品ドキュメント資産であり、プライベート マーケティング Web サイトのソース、テンプレート、ビルド出力ではありません。

## キャプチャルール

- 実際の製品言語とテーマ コントロールを使用します。ラベルを英語のスクリーンショットに翻訳したり、成功した結果をでっち上げたりしないでください。
- デモ アカウントを使用して、すべての画像の個人メッセージ、ファイル名、資格情報、受信者の PIN、ネットワーク アドレス、およびブラウザーのクロムを検査します。サインインしたゲスト ディスクまたはイメージを含むセッション/Cookie エクスポートを決して公開しないでください。
- 現在のワークベンチ キャプチャには、一般的なデモンストレーション タスクのステータスと一般的な管理者アカウントのみが表示されます。タスクのペイロードは公開されません。
- 製品の設定をキャプチャ後もそのままにします。スクリーンショットを取得するためにユーザー データを削除したり、ビジネス ワークロードを再実行したりしないでください。
- `workbench-light.jpg` and `workbench-dark.jpg` はオリジナルです。ほとんどはフルページ キャプチャを使用します。アラビア語では、ブラウザのフルページ RTL キャプチャによってページが置き換えられるため、実際のビューポートが使用されます。ラベルや結果は変更されませんでした。
- 一部のライブ タスク ステータスの単語は、ローカライズされたビューでも英語のままです。これらの画像は、出荷された UI をレタッチするのではなく、意図的に保存しています。ゲスト オペレーティング システム、モデル応答、ユーザー定義名には個別の言語設定があり、UI セレクターによって翻訳されません。

README レンダラは、製品ロケールごとに両方の画像を必要とするため、英語のスクリーンショットに自動的にフォールバックせずに失敗します。 UI を更新するときは、両方のテーマを置き換えて、`node tools/screenshot-manifest.mjs` を使用してイメージ マニフェストを再生成します。ネットワーク/デバイス識別子とローカル キャプチャ ログをこのパブリック ディレクトリに保管しないでください。
