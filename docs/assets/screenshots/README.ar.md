# لقطات المنتج العام

هذه لقطات حقيقية لمنصة العمل Team AI Box، صورة فاتحة وصورة واحدة داكنة لكل لغة من لغات واجهة المستخدم الـ 17. إنها أصول توثيق المنتج، وليست مصدر موقع الويب الخاص بالتسويق أو القوالب أو مخرجات البناء.

## قواعد الالتقاط

- استخدام لغة المنتج الفعلية وضوابط الموضوع؛ لا تترجم الملصقات إلى لقطة شاشة باللغة الإنجليزية أو تخترع نتيجة ناجحة.
- استخدم حسابًا توضيحيًا وافحص كل صورة بحثًا عن الرسائل الشخصية وأسماء الملفات وبيانات الاعتماد وأرقام التعريف الشخصية لجهاز الاستقبال وعناوين الشبكة ومتصفح Chrome. لا تقم مطلقًا بنشر قرص ضيف تم تسجيل الدخول إليه أو تصدير جلسة/ملف تعريف ارتباط مع الصور.
- تُظهر لقطات طاولة العمل الحالية فقط حالة مهمة العرض التوضيحي العامة وحساب المسؤول العام. أنها لا تكشف حمولات المهام.
- حافظ على إعدادات المنتج كما كانت بعد الالتقاط. لا تقم بحذف بيانات المستخدم أو إعادة تشغيل أعباء العمل للحصول على لقطة شاشة.
- `workbench-light.jpg` and `workbench-dark.jpg` هي النسخ الأصلية. يستخدم معظمهم التقاط الصفحة الكاملة. تستخدم اللغة العربية إطار العرض الفعلي لأن التقاط المتصفح من اليمين إلى اليسار بملء الصفحة أدى إلى إزاحة الصفحة؛ لم يتم تغيير أي تسميات أو نتائج.
- لا تزال بعض كلمات حالة المهمة المباشرة باللغة الإنجليزية في طرق العرض المترجمة. تحافظ هذه الصور عمدًا على واجهة المستخدم التي تم شحنها بدلاً من تنقيحها. تحتوي أنظمة التشغيل الضيف والاستجابات النموذجية والأسماء المعرفة من قبل المستخدم على إعدادات لغة منفصلة ولا تتم ترجمتها بواسطة محدد واجهة المستخدم.

يتطلب عارض README كلتا الصورتين لكل لغة منتج ويفشل بدلاً من الرجوع بصمت إلى لقطة شاشة باللغة الإنجليزية. عند تحديث واجهة المستخدم، استبدل كلا الموضوعين وأعد إنشاء بيان الصورة باستخدام `node tools/screenshot-manifest.mjs`. احتفظ بمعرفات الشبكة/الجهاز وسجلات الالتقاط المحلية خارج هذا الدليل العام.
