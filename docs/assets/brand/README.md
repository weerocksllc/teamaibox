# Team AI Box mascot

The approved mint cube character is shared by the product and its public READMEs.
The private website consumes copies of these product-brand assets, never the
other way around. Website source does not belong in this repository.

- `mascot-master.png`: transparent production master (1254 × 1254).
- `mascot.png`: 512 px README rendition, displayed at 160 px.
- `../../../apps/web/public/brand/`: 256 px interface mark, 64 px favicon,
  and 180 px touch icon. These are generated by proportional resizing of the master.

Keep the same palette and silhouette in all languages and both themes. Keep
the product name as live text rather than embedding translated text in the image.
Do not recolor with CSS filters, distort the aspect ratio, or replace application
icons and status indicators with the mascot. Adjacent wordmarks use decorative
empty-alt images; standalone README images have the name as alternative text.

Placement: README heading; product login masthead and capability illustration;
authenticated sidebar; browser tab and touch icon. The website uses it in the
shared navigation/footer, hero illustration, network illustration and article
template. Historical product screenshots are not retouched to imply deployment.

Artwork was prepared with the built-in image generator from the approved design.
Production prompt: extract only the approved mint cube robot; preserve face,
pose, proportions, outlines, spark and highlights; remove text, miniatures,
paper and ground shadow; center on a transparent square with small even padding.

To refresh localized README headers, run `node tools/render-readmes.mjs`.
