**حوّل NVIDIA DGX Spark إلى مساحة عمل ذكاء اصطناعي لفريقك.** شغّل الذكاء الاصطناعي المحلي وتوليد الصور وأدوات المستندات على NVIDIA DGX Spark. يجمع Team AI Box ملفات الفريق والمراسلة والأجهزة الافتراضية في مساحة عمل مفتوحة المصدر عبر المتصفح.

## لماذا Team AI Box؟

- **مساحة موحدة:** واجهة وحسابات مشتركة للذكاء الاصطناعي والتعاون والأجهزة.
- **الأولوية للذكاء الاصطناعي المحلي.** شغّل استدلال النماذج على Spark، واربط واجهات API لنماذج خارجية عند الحاجة.
- **مصمم لـ DGX Spark.** ثبّته على Ubuntu ARM64 باستخدام حاويات NVIDIA GPU والمحاكاة الافتراضية KVM.
- **مفتوح للمساهمة:** الشيفرة الأصلية بترخيص MIT، و17 لغة وسمتان فاتحة وداكنة مع حفظ الاختيار اليدوي. الإنجليزية هي اللغة الافتراضية.

### مساحة العمل والتنقل اليومي

- استخدم مساحة عمل واحدة في المتصفح للذكاء الاصطناعي المحلي وتعاون الفريق والأجهزة الافتراضية على جهاز DGX Spark واحد.
- تصفّح التطبيقات حسب الفئة، وابحث في دليل التطبيقات، وافتح تطبيقًا من الشريط الجانبي.
- اطّلع على تقدم التحميل والتوافر وحالة الخدمة لكل تطبيق.
- تابع الأعمال المنتظرة والجارية والمكتملة والفاشلة والملغاة في مركز المهام، وافتح النتائج المتاحة.
- اطّلع على دعوات العرض اللاسلكي المعلّقة في قائمة الإشعارات، وافتح تطبيق العرض اللاسلكي للرد عليها.
- اختر من بين 17 لغة للواجهة، بما فيها العربية من اليمين إلى اليسار؛ الإنجليزية هي اللغة الافتراضية حتى تختار لغة أخرى.
- استخدم المظهر الفاتح أو الداكن أو مظهر النظام؛ تُحفظ اختياراتك اليدوية للغة والمظهر عند تحديث الصفحة وإعادة تسجيل الدخول والتنقل بين التطبيقات.

<a id="feature-assistant"></a>

### مساعد الذكاء الاصطناعي ومسارات عمل الوكيل الخاضعة للتحكم

- ابدأ محادثات واحفظ سجلّها وأعد فتح النقاشات السابقة.
- اختر الوضع التلقائي أو الإجابة أو الوكيل للطلب الحالي.
- أرفق عدة ملفات بالطلب واحذف المرفقات قبل الإرسال.
- اقرأ الردود أثناء توليدها، وأوقف تنفيذًا نشطًا، واستأنف تدفق أحداثه بعد إعادة الاتصال.
- راجع تفاصيل النموذج المعادة ونشاط الأدوات والمصادر والاستخدام؛ ونزّل الملفات الناتجة عندما ينتجها التنفيذ.
- راجع نطاق إجراء الوكيل الذي يتطلب تأكيدًا، ثم وافق على الإجراء أو ارفضه.
- شغّل أعمال الوكيل في بيئة معزولة لكل مستخدم ذات مساحة عمل دائمة؛ وتخضع الأدوات والوصول إلى الشبكة لسياسة المسؤول.

<a id="feature-drawing"></a>

### توليد الصور بالذكاء الاصطناعي

- ولّد صورة من وصف نصي باستخدام نموذج الصور المتاح؛ التطبيق الحالي ليس محرر صور ولا أداة لإعادة رسم مناطق محددة من الصورة.
- اختر نمط التوليد التلقائي أو السريع عندما تدعمه إعدادات النموذج المتاح.
- اختر نسبًا مربعة أو أفقية أو عمودية، وأبعاد إخراج مدعومة، وبذرة توليد عشوائية أو ثابتة.
- اطلب إخراجًا بتنسيق PNG أو WebP أو JPEG، وعاين النتيجة ونزّل الصورة.
- تابع قائمة الانتظار وتقدم التوليد، وألغِ العمل، واستعد المهمة الحالية بعد إعادة فتح الصفحة.
- راجع النموذج المستخدم فعليًا ومعلمات التوليد المسجّلة مع النتيجة.

<a id="feature-ocr"></a>

### التعرّف على النص وتصحيحه

- ارفع ملف PNG أو JPEG أو WebP أو PDF، أو اختر ملفًا موجودًا في مساحة ملفات الفريق.
- قدّم تلميحًا للغة وتعرّف على النص أو جداول Markdown أو صيغ LaTeX ضمن قدرات النموذج المحدد.
- راجع نتائج التعرّف حسب الصفحة وكتلة النص، ثم صحّح النص المتعرّف عليه يدويًا.
- صدّر المحتوى المراجع كنص أو Markdown أو JSON.
- أرسل نتيجة تعرّف محفوظة إلى الترجمة دون رفع المصدر أو التعرّف عليه مرة أخرى.
- تابع مهام التعرّف وألغِها. لا يوفّر النموذج الحالي إحداثيات المربعات المحيطة أو درجات الثقة.

<a id="feature-transcription"></a>

### تفريغ الكلام المسجّل والمباشر

- اختر صوتًا أو فيديو محليًا أو من مساحة ملفات الفريق: WAV أو FLAC أو OGG أو WebM أو MP3 أو M4A أو AIFF أو MP4.
- عاين الوسائط الأصلية واستخدم الكشف التلقائي عن اللغة أو تلميحًا للغة مدعومة.
- راجع مقاطع التفريغ ذات الطوابع الزمنية وحرّر نصوصها.
- صدّر النص أو JSON أو ملفات الترجمة المصاحبة SRT أو WebVTT.
- مرّر تفريغًا محفوظًا إلى الترجمة، وتابع مهمة التفريغ الحالية أو ألغِها.
- فرّغ إدخال الميكروفون مباشرة عندما يتوفر HTTPS وإذن المتصفح وMediaRecorder وخدمة الوقت الحقيقي.
- استخدم الطوابع الزمنية للكلمات أو فصل المتحدثين مع ملفات الإعداد الداعمة فقط؛ يتطلب المسار التجريبي لفصل المتحدثين إدخالًا بتنسيق WAV.

<a id="feature-translation"></a>

### ترجمة النصوص والملفات والوسائط

- اختر من دليل يضم 60 لغة يدعمها النموذج، واكتشف لغة المصدر تلقائيًا، أو اختر لغتي المصدر والهدف وبدّل بينهما. لا يضمن ذلك جودة متساوية لكل أزواج اللغات.
- ترجم نصًا مكتوبًا أو ملصقًا وقارن المقاطع الأصلية بالمترجمة.
- ارفع صورة أو ملف PDF، أو اختره من مساحة ملفات الفريق؛ وتعرّف على نصه قبل الترجمة عندما تكون خدمة OCR جاهزة.
- ترجم الصوت أو الفيديو المدعوم عبر التفريغ، مع الحفاظ على توقيت المقاطع عندما تكون خدمة التفريغ جاهزة.
- أعد استخدام نتائج OCR أو التفريغ المحفوظة ونزّل النتائج الوسيطة المتاحة.
- حرّر النص المترجم وصدّره كنص أو Markdown أو JSON؛ وتدعم نتائج الصوت والفيديو أيضًا SRT وWebVTT.
- تابع مراحل الاستخراج والتفريغ والترجمة، وألغِ العمل، واستعد المهمة الحالية بعد إعادة الفتح.
- لغات الترجمة منفصلة عن لغات الواجهة وتغطية OCR/ASR. تعتمد ترجمة PDF على النص، ولا تعيد إنشاء التخطيط الأصلي ولا توفّر تحريرًا عامًا لملفات DOCX/XLSX.

<a id="feature-messaging"></a>

### مراسلة الفريق

- ابحث عن الزملاء، وابدأ محادثات مباشرة، وأنشئ محادثات جماعية مسمّاة بأعضاء تحددهم.
- رشّح جميع المحادثات أو غير المقروءة أو الجماعية، وابحث في المحادثات والرسائل المسموح لك بالوصول إليها.
- أرسل نصوصًا ومرفقات ملفات، ونزّل الإصدار الأصلي لملف المرفق.
- استقبل الرسائل مباشرة، واستعد سجل المحادثة عند إعادة الاتصال، وتابع مواضع القراءة والرسائل غير المقروءة، واطّلع على حالة اتصال الأعضاء.
- أرسل باستخدام Enter، وأدرج سطرًا جديدًا باستخدام Shift+Enter، وتنقّل بين قائمة المحادثات والمحادثة على الشاشات الضيقة.
- احذف رسالة من عرضك الخاص أو امسح سجل محادثتك فقط؛ لا تُحذف سجلات المشاركين الآخرين.
- احذف محادثة من قائمتك الخاصة دون مغادرة المجموعة؛ قد تظهر مجددًا عند وصول رسالة جديدة.

<a id="feature-drive"></a>

### مساحة ملفات الفريق والتعاون على الملفات

- نظّم مساحات الملفات الشخصية والجماعية باستخدام المجلدات والتنقل عبر مسار المجلد.
- بدّل بين عرض القائمة والشبكة، وراجع تفاصيل الملفات، وابحث عن الملفات والمجلدات، واطّلع على التغييرات الحديثة.
- ارفع عدة ملفات، وتابع تقدم الرفع، وألغِ عملية رفع.
- استأنف رفع ملف كبير متعدد الأجزاء باختيار الملف نفسه مرة أخرى؛ يتحقق الخادم من الأجزاء المرفوعة.
- أنشئ مجلدات وأعد تسمية الملفات والمجلدات أو انقلها أو انسخها.
- عاين الصور والصوت والفيديو والنصوص وملفات PDF المدعومة، ونزّل الملفات؛ يعتمد تشغيل الوسائط على المتصفح.
- ارفع إصدارًا جديدًا من الملف، وراجع سجل الإصدارات، ونزّل الإصدارات السابقة.
- انقل العناصر إلى سلة المحذوفات واستعدها.
- شارك داخليًا مع أعضاء أو فرق بأذونات عرض أو تحرير ومدة صلاحية اختيارية؛ ليست هذه مشاركة مجهولة عبر رابط عام.
- تصفّح الملفات والمجلدات المشتركة معك، مع إعادة التحقق من الوصول وفق الأذونات والعضوية الحالية.

<a id="feature-casting"></a>

### عرض لاسلكي متوافق مع AirPlay

- ابدأ وأوقف جهاز استقبال مؤقتًا لأجهزة Apple المتوافقة على الشبكة المحلية نفسها، باسم ورمز PIN خاصين به.
- اختر مدة تشغيل للمستقبِل قدرها 15 أو 30 أو 60 أو 120 دقيقة؛ يؤدي الإيقاف أو انتهاء المدة إلى إنهاء الإعلان عنه في الشبكة وإمكانية المشاهدة.
- اقصر المشاهدة عليك أو على أعضاء محددين أو فريق؛ وادعُ مشاهدين يمكنهم قبول الدعوة أو رفضها.
- شاهد الشاشة وشغّل الصوت في المتصفح؛ قد تتطلب قواعد التشغيل التلقائي نقرة لتفعيل الصوت.
- اعرض المشاهدين المتصلين وأزلهم؛ يستطيع المسؤول إيقاف جلسة دون أن يحصل على إذن لمشاهدة المحتوى الخاص.
- اطّلع على حالات الانقطاع وإعادة الاتصال، مع إعادة التحقق من إذن المشاهدة عند الانضمام مجددًا.
- يتطلب بيئة تشغيل وسائط جاهزة، وإمكانية اكتشاف الأجهزة عبر الشبكة المحلية، وإصدارات متوافقة من المتصفح والجهاز. لا يوفّر العرض في المتصفح إخراج HDMI أو تشغيل DRM/FairPlay أو اعتماد Apple.

<a id="feature-phones"></a>

### هواتف Android افتراضية تحتفظ ببياناتها

- أنشئ هواتف Android مستقلة من ملفات النظام المثبّتة، مع الاحتفاظ بتطبيقات وبيانات كل هاتف بين الجلسات.
- شغّل الهواتف الفردية وأوقفها وأعد تشغيلها وتسميتها واحذفها بإجراء صريح.
- تحكم في Android بلوحة المفاتيح والمؤشر وأزرار الرجوع والرئيسية والتطبيقات الأخيرة ومستوى الصوت.
- استخدم الصوت والعرض بملء الشاشة، وأعد الاتصال، أو انقل اتصال الهاتف النشط إلى صفحة أخرى.
- ارفع الملفات إلى الهاتف ونزّل الملفات من مجلد النقل Team AI Box فيه.
- ثبّت ملفات APK الخاصة بك بعد التأكيد؛ لا تُمنح أذونات تطبيقات Android بصمت.
- زوّد الكاميرا الافتراضية بصورة أو فيديو أو كاميرا المتصفح عند توفر الدعم؛ وتتطلب كاميرات USB الفعلية ومصادر الشبكة أيضًا إعدادًا وأذونات من المسؤول.
- اسمح مؤقتًا بتصحيح ADB المقيّد بجهاز محدد عبر وسيط قصير العمر، باستخدام أدوات ADB القياسية وعميل الوسيط Node.js.
- راجع عند الطلب إحصاءات معدل الإطارات وفقدان الحزم وزمن الذهاب والإياب للاتصال؛ وهي ليست ضمانًا لزمن التأخير من الطرف إلى الطرف.
- اختر ملف نظام Google Play فقط عندما تتوفر موارده؛ لا يعني التوفر اعتماد Play Protect أو ضمان عمل كل تطبيق Android.

<a id="feature-computers"></a>

### حواسيب Windows وLinux الافتراضية

- أنشئ حواسيب ARM64 مستقلة تعمل بنظام Windows/Linux مع اختيار موارد المعالج والذاكرة وحجم القرص.
- شغّل حاسوبًا، وأوقف تشغيله بالطريقة المعتادة، واحذف حاسوبًا متوقفًا بعد تأكيد صريح.
- افتح شاشة افتراضية في المتصفح لرؤية البرنامج الثابت والإقلاع والتثبيت وشاشات نظام التشغيل دون تسجيل الدخول أولًا إلى سطح مكتب بعيد.
- استخدم لوحة المفاتيح والمؤشر والصوت والعرض بملء الشاشة وأدوات إعادة الاتصال.
- افتح الكمبيوتر الافتراضي نفسه في عدة علامات تبويب أو نوافذ للمتصفح.
- ادعُ زملاء لمشاهدة الشاشة أو التحكم بها، وألغِ صلاحية وصولهم.
- سلّم التحكم إلى مشارك آخر، أو تخلَّ عنه، أو استعده بصفتك المالك؛ واختر وضع متحكم واحد أو التحكم المشترك.
- ارفع ISO للتثبيت مع أدوات الإيقاف المؤقت والاستئناف والإلغاء، أو اختر ISO موجودًا في مساحة ملفاتك الشخصية أو مساحة الفريق.
- اربط وسيطًا ضوئيًا افتراضيًا أو أخرجه، واختر الإقلاع من القرص لمرة واحدة؛ تغيير الوسيط لا يعيد تشغيل الحاسوب تلقائيًا.
- ثبّت نظام تشغيل ARM64 خاصًا بك ومصرّحًا باستخدامه، واستخدم سطح المكتب البعيد الاختياري بشكل منفصل. تبقى مسؤولية ترخيص Windows عليك؛ لا يتضمن المنتج Windows مفعّلًا مسبقًا أو دعمًا عامًا لأنظمة الضيوف x86.

<a id="feature-administration"></a>

### الإدارة والأذونات والأمان

- أنشئ أعضاء محليين، وأدر حالات الحسابات، وأعد تعيين كلمات المرور عندما يسمح دورك بذلك.
- عيّن الأدوار المدمجة، وراجع الأذونات، وأدر عضوية الفريق مع ضمانات تحمي عمليات المالك.

## ما هو NVIDIA DGX Spark؟

NVIDIA DGX Spark نظام مكتبي مدمج للذكاء الاصطناعي يعتمد على GB10 Grace Blackwell Superchip. يجمع تكوين 128 GB معالج Arm ذا 20 نواة ووحدة Blackwell GPU وذاكرة نظام موحدة بسعة 128 GB وعرض نطاق 273 GB/s. تحدد NVIDIA قدرة حسابية نظرية للذكاء الاصطناعي تصل إلى 1 PFLOP بدقة FP4 مع استخدام التناثر.

الذاكرة الموحدة ذاكرة نظام مشتركة وليست VRAM مخصصة. تختلف المواصفات باختلاف التكوين؛ ولا تضمن القدرة النظرية سرعة التطبيقات أو عدد المستخدمين المتزامنين.

يوفر DGX Spark القدرة الحسابية، ويضيف Team AI Box واجهة مشتركة للاستدلال المحلي وتوليد الصور والتعرف على النصوص والتفريغ الصوتي والترجمة والتعاون. يُنزل التثبيت الأول من المصدر الاعتماديات ويبني بيئة التشغيل قبل الإعداد.

[مواصفات NVIDIA DGX Spark الرسمية](https://docs.nvidia.com/dgx/dgx-spark/hardware.html)

Team AI Box مشروع مستقل من Weerocks LLC وليس منتجًا أو اعتمادًا أو تأييدًا من NVIDIA. تحدد متطلبات التثبيت أدناه الأجهزة المدعومة في المشروع.

## التثبيت على DGX Spark جديد

تحتاج **DGX Spark غير مثبت عليه المنتج مع Ubuntu 24.04 ARM64** وDocker Engine وCompose v2 وتعريفات ودعم حاويات NVIDIA وKVM وGit وPython 3.10+. وفر عدة مئات من الجيجابايت مؤقتاً للنماذج والبناء والحزمة. لا تنفذ تثبيتاً جديداً فوق بيانات قائمة.

```sh
git clone https://github.com/weerocksllc/teamaibox.git
cd teamaibox
sudo bash install/from-source.sh
```

نفذ الأوامر **على Spark**. ينزل البرنامج المدخلات والنماذج ويبني الصور وينشئ حزمة كاملة دون اتصال ثم يثبتها. البناء الأول يحتاج الإنترنت والوقت؛ الاستنساخ وحده ليس تثبيتاً. يعاد استخدام Docker/NVIDIA.

### الفحص والاستئناف

يفحص `--check` المتطلبات. عند الانقطاع احتفظ بـ `/var/tmp/teamaibox-source-build` وأعد **الأمر نفسه** لاستخدام التنزيلات والمراحل المتحققة. لا تمسح الذاكرة المؤقتة ولا تبدأ بناءات متنافسة. المصادر الرسمية هي الافتراضية. عند تعذر الوصول راجع [الدليل](install/SOURCE-INSTALL.ar.md) للبدائل أو انقل ذاكرة مؤقتة/حزمة كاملة متحققة؛ توافر المرايا غير مضمون. تغيير الشيفرة يتطلب `--work-dir` جديداً دون تجاوز نقاط التحقق.

```sh
sudo bash install/from-source.sh --check
sudo bash install/from-source.sh
```

### بعد التثبيت

1. افتح `https://<BOX_LAN_IP>/` بعنوان الشبكة الحالي وتحقق أن شهادة HTTPS المحلية تخص جهازك.
2. ادخل بـ `admin` / `admin` ثم **غيّر كلمة المرور الأولية** وأنشئ حسابات عادية. لا تعرض بيانات الدخول الافتراضية للإنترنت.
3. انتظر جاهزية التطبيقات واختر اللغة والسمة من الملف الشخصي.
4. وفر ISO مرخصة لـ Windows/Linux ARM64 وترخيص النظام. للتثبيت دون اتصال جهز الحزمة كاملة أولاً واتبع [دليلها](install/README.ar.md)؛ تجهيز المصدر يحتاج اتصالاً.
